## 步骤 3：统一 clear* 函数（低风险，新增 ~20 行）

**文件**：`www/asa-admin.html`
**位置**：新增工具函数，约在 `clearIconSelection` 之前

**新增**：
```javascript
/**
 * 将 badge 从隐藏容器移入可见占位符（仅当 badge 当前在隐藏容器中时）
 * @param {string} badgeId - 如 'icQtyBadge0_1'
 * @param {HTMLElement} targetEl - 目标占位符元素
 */
function relocateBadgeToPlaceholder(badgeId, targetEl) {
  var badge = document.getElementById(badgeId);
  if (!badge || !targetEl) return;
  // 仅在 badge 当前父容器隐藏时才移动
  var parent = badge.parentElement;
  if (parent && (parent.style.display === 'none' || getComputedStyle(parent).display === 'none')) {
    targetEl.textContent = '';                          // 清空 '+'
    targetEl.appendChild(document.createTextNode('+')); // 重新加 '+'
    targetEl.appendChild(badge);                        // 移入 badge
  }
}
```

**调用点改造**（3 处统一调用）：

| 原代码 | 改为 |
|--------|------|
| `clearIconSelection` 板块级 (~L18950) 手工移 badge | `relocateBadgeToPlaceholder('icQtyBadge'+bi, newPh)` |
| `clearIconSelection` 图标组标题 (~L19013) 手工移 badge | `relocateBadgeToPlaceholder('icQtyBadgeIGTitle'+oCtx.bi+'_'+oCtx.di, ph)` |
| `clearDescImageSelection` (~L18729) 手工移 badge | `relocateBadgeToPlaceholder('icQtyBadge'+bi+'_'+di, ph)` |

> 注意：步骤 2 实施后，板块级的 `clearIconSelection` 不再需要移 badge（template 已共享），此步骤仅保留 desc_row 和 icon_group_title 的调用。
