## 一、新增 RCON 命令：容器箱改名

```
TransferIdentityFix.RenameContainer <objName|尾部数字> <新名字>
```

### 参数

| 参数 | 说明 |
|---|---|
| `<objName>` | 容器的**持久对象名**，如 `StorageBox_Barrel_C_2146633556`；也可只传**尾部实例数字**（≥4 位），如 `2146633556` |
| `<新名字>` | **可含空格**（整体作为名字）。限制：非空、≤ **60 UTF-8 字节**（约 20 个汉字）、不含控制字符 |

### 成功返回

```json
{"ok":true,"objName":"CryoFridge_C_2143602189","class":"CryoFridge_C","field":"BoxName",
 "old":"焦土常用","new":"TIF-TEST-01","readback":"TIF-TEST-01","verified":true,"dup":1,
 "detail":"objName=CryoFridge_C_2143602189 class=CryoFridge_C old=焦土常用 new=TIF-TEST-01 readback=TIF-TEST-01 verified=1 dup=1"}
```

| 字段 | 含义 |
|---|---|
| `objName` | 命中容器的持久名（可直接用于后续调用） |
| `class` | 完整类名 |
| `field` | 恒为 `"BoxName"` |
| `old` / `new` | 改动前 / 目标名字 |
| `readback` | 写入后**回读**到的值 |
| `verified` | `readback == new`。建议前端**以 `ok:true` 为准**；`verified:false` 表示回读不一致（异常情况） |
| **`dup`** | **新增**：当前与新名字**同名**的容器数量（含自身，≥1 属正常） |
| `detail` | 人类可读摘要（供只解析文本的旧逻辑使用） |

### 失败返回

```json
{"ok":false,"error":"...","detail":"...","id":"...","hint":"..."}
```

| `error` 值 | 触发条件 | 建议前端提示 |
|---|---|---|
| `usage: RenameContainer <objName\|instanceSuffix> <new name>` | 参数缺失 | 用法错误 |
| `name empty` | 名字为空 / 全空白 | 请输入名字 |
| `name too long (N bytes, max 60)` | 超长（按 **UTF-8 字节**计） | 名字太长 |
| `name contains control char` | 含控制字符 | 名字含非法字符 |
| `world/level not ready` | 世界未就绪 | 稍后重试 |
| `container not found` | 未找到（**可能附带 `hint`**） | 见下方 `hint` |
| `ambiguous id (N matches)` | 尾部数字命中多个对象 | 请传完整 `objName` |

**`hint` 字段**（仅在目标 id 命中的是**非容器**设施时出现）：

```
this id belongs to a non-container structure (StructureBP_Coffin_C); only container boxes can be renamed
```

> 设计原因：**只有容器箱有游戏官方同步通道**（`NetUpdateBoxName`）。床 / 棺材 / 牌子没有对应通道，已按设计**拒绝**改名。

### 如何取得 `<objName>`

直接复用**已有**命令（无需新增），详见同目录 `InvProbe库存扫描命令_前端调用文档.md`：

```
TransferIdentityFix.InvProbe <class关键字> <tribeId，0=不限> <最多容器数>
```

返回中 `list[].id` **就是** `objName`，可原样喂给改名命令。

> ⚠️ `InvProbe` 内部有 `if (itemCount <= 0) continue;` —— **空箱子会被跳过**，只列**有物品**的容器。

### 支持的容器范围

`APrimalStructureItemContainer` 及其**全部子类**：
普通/巨型/金属储物箱、保险柜(Vault)、低温冰箱(CryoFridge)、展示台(DisplayCase)、泰克专储、工业熔炉、化学台等。

## 三、新增字段：`colorRegions`（建筑涂装取色）

出现在 **`facilities[]`** 与 **`structures[]`** 的条目上。
**仅当该设施存在染色数据时才出现此字段**；无染色数据时**整个字段缺省**（不是空数组）。

### 示例

```json
"colorRegions": [-1,-1,-1,-1,67]
```

### 解析规则（4 条，务必按此实现）

1. **变长数组**，长度 1–6 不定 —— UE **只序列化非默认值**，**缺失的下标 = 该区域从未染色**。
2. **下标 = 染色区域号（0–5）** —— ARK 结构共有 6 个可染色区域。
3. **值 `-1` = 该区域未设置**（**注意：不是"颜色 0"**，颜色 0 是合法值）。
4. **值是 ARK 调色板索引，不是 RGB** —— 换算成真实颜色需要游戏内置调色板表，**离线数据里没有**，需前端**自备「索引 → 颜色」映射**。

### 实服实测样例（Isl，箱子"随身"）

```json
{"key":"2b821d3581ae284ea87ac5c8a098cea3","class":"StorageBox_Huge_C_2144016418","name":"随身",
 "tribeId":1621369181,"tribeName":"北境游骑兵","x":-267167.82,"y":-260057.37,"z":-2862.50,
 "colorRegions":[-1,-1,-1,-1,67],"isPlayerStructure":1}
```

**含义**：只有**区域 4** 染色，色号 **67**；区域 0–3 未设置；区域 5 从未染色（数组未包含该下标）。

### 实测覆盖率（Isl）

| 段 | 总条数 | 带 `colorRegions` |
|---|---:|---:|
| `facilities` | 1316 | **92** |
| `structures` | 124 | **0**（床 / 牌 / 棺材这类可命名设施本身不带染色数据） |

## 四、`structures` 收录范围变更 ⚠️

| 变更 | 类名 |
|---|---|
| **新增收录** | `Sign_Wall_Metal_C`（金属壁挂牌）、`Sign_Wall_Wood_C`（木质壁挂牌） |
| **继续排除** | `Sign_Wall_Stocking_C`（圣诞袜）、`Sign_PaintingCanvas_C`（画布）、`Sign_WarMap_C`（战争地图） |

**实服实测影响（Isl）**：`structures` 从 **87 → 124**（壁挂牌新增 **15** 面）。

> 背景：此前「壁挂牌」**从未**进入过收录名单，导致玩家放置的壁挂告示牌在下发数据中完全缺失（用户反馈"放了写『工作间』的牌子前端找不到"）。现已修复。
>
> 壁挂牌的文字取自 `SignText` 字段，输出在条目的 **`name`** 上（与其他牌/床一致）。

**对前端的影响**：若你此前按 `class` 做**白名单/枚举**过滤，请把这两个类名补进去；若按**前缀/包含**匹配则无需改动（只会多出条目，不会少）。

## 五、两个诊断字段（可完全忽略）

| 字段 | 内容 | 用途 |
|---|---|---|
| `signDiag[]` | 存档中**所有**类名含 `Sign` 的对象（**含未被收录的**），字段：`class / key / name / tribeId / inWhitelist / hasPos / x / y / z` | 仅用于排查"某个牌子为什么没出现" |
| `colorTags[]` | 结构属性中名字含 `Color` 的属性标签，如 `StructureColors\|Int16Property\|2` | 纯诊断，确认颜色字段是否落盘 |

前端**可以完全不读取**这两个字段。

## 六、已知遗留（请前端留意）

1. ⚠️ **改名后客户端是否"立即"刷新，尚未人工验证**。
   服务端已在写字段后调用游戏官方 RPC `NetUpdateBoxName`，但**"其他在线玩家不重登、能否立刻看到新名字"需要游戏内目视确认**。
   若实测发现"要重登/换图才变"，请立刻反馈 —— 我们再补走官方 `ProcessEditText` 通道。
2. 容器改名**仅支持容器箱**（床 / 棺材 / 牌子无官方同步通道，按设计返回 `container not found` + `hint`）。
3. `colorRegions` 目前**只在有染色数据时输出**；若前端需要"恒定 6 元素数组（未染色补 -1）"，请提出，我们可以改成定长输出。
