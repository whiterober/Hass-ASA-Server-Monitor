## 二、研读结论（关键事实与坑，均已核实）

### 2.1 机制事实（文档定案）

1. **沙尘暴** = 三层结构（§13/§14.1）：掷骰层 `BP_RAG_DayWeather_WeatherSystem_C`（6 预设，沙尘暴=idx3）→ 区域层 `Agent`（4 区域权重）→ 效果层 `BP_RAG_WeatherEffects_C`（`bInSandstormTrigger` 区域闸门 + `SandstormAmount`）。
   "沙尘暴只在沙漠" = **全局抽中 + 效果层仅在沙漠触发卷生效**（不是沙漠独立天气）。
2. **雷暴** = 普通**全局天气预设**（§17.1：idx4 = `WeatherPreset_RAG_ElectricalStorm`；**无区域绑定、无掩膜、无独立 actor**）。
   wiki 中"区域悬停劈雷"是 **Sco（焦土）专属**特性，Rag 不适用（§17 + 电风暴澄清文档）。
3. **火山** = `BP_VolcanoManager_C`（世界唯一）；事件间隔 `VolcanoIntervalMinMax=[5000,15000]` 秒（**必须 `probe=` 读**）；单次持续 `VolcanoEventLength=120` 秒；`ETA = TimeNextVolcanoEvent − worldTime`（秒级可靠，v121+）。
   - `TimeNextVolcanoEvent=0` ⇒ **未排期**（服务器重启后需等一次事件结束才自动排期）——显示「空闲期·未排期」，勿显示负数。
   - `LocalVolcanicIntensity`/岩浆/弹幕字段**恒 0**（参考点未解）⇒ **只承诺 `WorldVolcanicIntensity`**。

### 2.2 判定链实测定案（2026-10-10 22:2x，本次新增，直接定死实现口径）

| 检查项 | 实测值 | 结论 |
|---|---|---|
| `weatherState.currentWeatherId` | **null** | ✗ 不可用于判天气（文档 §14.3 确认） |
| `wxSemantics.enumIndices.*` | **全 null** | ✗ 不可用 |
| `weatherHistory.current` | **`'ElectricalStorm'`**（name 格式） | ✔ **Rag 天气身份的唯一可读源**（v122b24）；实测时正刮雷暴 |
| `weatherHistory.lastChange` | `{to:'ElectricalStorm', agoSec, atSource, changes:1}` | ✔ "当前天气何时开始"（agoSec）→ 卡底进度 |
| `sandstorm` 命令 | `supported:1, active:0, pct:7.317, suc:1107.7` | ✔ 沙尘暴专用链（区域闸门判定） |
| 火山 `actor` | `active:0, tnext:0, ends:0, inten:0`（空闲期） | ✔ 正常（未排期） |

**⇒ 定案**：Rag 的"当前在刮什么"= `weatherHistory.current`（字符串名）；沙尘暴另加 `sandstorm.active` 双保险；"已持续"= `lastChange.agoSec ÷ 走针`（前端 `lbWxHistAgo` 现成）。

### 2.3 必须绕开的坑（文档固化）

1. `sandstorm` 的 `slots[].base/ratio` 不可依赖（重启后未初始化 + 本就是游戏草稿数组）⇒ **只用 `weights.sandstormPct` / `probsPct[]`**。
2. `timer.transitionDuration` 不可靠 ⇒ 过渡时长用 `WeatherTransitionTimeMin/Max`（=40~80 s）。
3. Rag 变天间隔 `changeIntervalMin/Max = 1500/2500 s`（比 Sco 快得多，徽章"平均每X一次"口径随之不同——现有链已按图取数，无需特判）。
4. `TimeNextVolcanoEvent` 的 `0` = 未排期（不是"已过时间"）。
5. 火山 `VolcanoIntervalMinMax` 直接读 `actorProps` 会得到垃圾值（8 字节槽按 double 解）——**必须 `probe=` 读**。
