# ARK 自定义食谱（Custom Consumable）效果值算法报告

> 日期：2026-09-18 ｜ 用途：推算自定义料理「食物+/水+/生命+」等数值，供前端展示
> 算法来源：**ARK 官方 Wiki** `ark.wiki.gg/wiki/Custom_Consumable`（"Ingredient Effects" 章节，含 Reddit 工具作者原始推导）
> 本地方向：结合本项目实服存档字段测绘结果，给出可落地的对接方案
> 适用版本：公式出自 **ARK: Survival Evolved v224**；**ARK: Survival Ascended 尚未实测校准**（见 §7）

---

## 1. 结论速览

1. **效果值可以算出来**，公式是纯线性的：**烹饪技能系数 × Σ(食材系数 × 数量)**，再 **+1**
2. **计算不需要存档里存在效果字段** —— 存档只存「技能 + 食材清单」，效果是**按公式推导**的
3. 每个属性（生命 / 耐力 / 食物 / 水 / 重量）**各有一套食材系数**，独立求和
4. **食物属性只对「菜」生效，水属性只对「饮」生效**（用**类名**区分：`PrimalItemCustomFoodRecipe_*` 为菜、`CustomDrinkRecipe_*` 为饮）
5. 决定成败的是**制作食谱那一刻的烹饪技能**（不是烹饪时的技能），最大约 1290%（Lv110 全点）

## 2. 核心公式

### 2.1 属性值

$$\text{Stat} = 1 + \left(\text{CraftingSpeed} \times 1.5625 - 0.3125\right) \times \sum_{i} \left(5 \times s_i \times q_i\right)$$

| 符号 | 含义 |
|---|---|
| $\text{Stat}$ | 该项属性的最终收益值（生命 / 耐力 / 食物 / 水） |
| $\text{CraftingSpeed}$ | **制作该食谱时的烹饪技能**，小数形式（100% → `1.0`；1290% → `12.90`） |
| $s_i$ | 第 $i$ 种食材在**该项属性**上的系数（见 §4 表） |
| $q_i$ | 第 $i$ 种食材的**数量**（堆数/个数） |

> **Focal Chili 修正**：辣椒酱加 **+100% 烹饪技能**，换算到公式里即 **CraftingSpeed 再加 `1.0`**（不是乘 1.1，是加 1）。

### 2.2 重量

$$\text{Weight} = 0.1 + 0.2 \times \sum_{i} w_i$$

其中 $w_i$ 为各食材重量贡献（§4 表最后一列），**食材自身重量另行累加**。

### 2.3 技能系数速查（CraftingSpeed 小数 → 括号内系数）

| 烹饪技能 | CraftingSpeed | 公式系数 ($1.5625x-0.3125$) | 相对 100% 技能 |
|---|---|---|---|
| 0% | 0.00 | −0.3125 | 负值（必亏） |
| 50% | 0.50 | 0.4688 | 0.38× |
| 100% | 1.00 | 1.2500 | 1.00×（基准） |
| 300% | 3.00 | 4.3750 | 3.50× |
| 500% | 5.00 | 7.5000 | 6.00× |
| 1000% | 10.00 | 15.3125 | 12.25× |
| 1290%（Lv110 满点） | 12.90 | 19.8438 | 15.88× |
| 1590%（Lv140 + 辣椒酱） | 15.90 | 24.5313 | 19.63× |

> ⚠️ 技能低于 **20%** 时系数为负，做出来的食谱实际是**赔的** —— 与 Wiki "Level ~90 之前会掉属性" 的描述方向一致。

## 3. 关键规则（Wiki Notes 整理）

| # | 规则 |
|---|---|
| 1 | **技能时间点**：用**制作食谱（从 Note 生成）那一刻**的烹饪技能，**不是**之后用食谱烹饪时的技能 |
| 2 | **最大技能**：1290%（Lv110 全部点数投技能）或 1590%（Lv140 + Focal Chili） |
| 3 | **食材上限**：一个食谱最多 **8 组**食材 |
| 4 | **禁用材料**：药品（Drugs）与已做好的菜（premade Dishes）不能作为食材 |
| 5 | **蛋类特例**：若配方用蛋，则该食谱**绑定该种蛋** |
| 6 | **回复不是即时的**：食物/水/耐力以 **固定 1.05 点/秒** 回复；数值越高，状态效果持续越久 |
| 7 | **生命回复**：也是缓慢回血；同时吃「菜 + 饮」**不会**加快回血速率 |
| 8 | **满值截断**：任一回血/回复效果在对应属性**到达上限**时立即结束（例：上限 100 食物，吃下 +200 的菜，回满 100 即停止） |
| 9 | **只对人类有效**：喂给生物无效果 |
| 10 | **保质期**：标准 **48 小时**，可堆叠 **20** |

## 5. 计算示例

### 5.1 示例 A：技能 300% + 20 块熟肉

- CraftingSpeed = `3.0` → 系数 = 3.0 × 1.5625 − 0.3125 = **4.375**
- 熟肉食物系数 0.2，数量 20 → Σ = 5 × 0.2 × 20 = **20**
- **食物 = 1 + 4.375 × 20 = 88.5**
- 生命：系数 0.11 → 5 × 0.11 × 20 = 11 → **生命 = 1 + 4.375 × 11 = 49.1**

### 5.2 示例 B：技能 1000% + 5 个蛋（生命向）

- 系数 = 10 × 1.5625 − 0.3125 = **15.3125**
- 蛋生命系数 0.8，数量 5 → Σ = 5 × 0.8 × 5 = **20**
- **生命 = 1 + 15.3125 × 20 = 307.25**

### 5.3 示例 C：技能 100%（基准）+ 1 组白果

- 系数 = 1.25；白果食物 0.0525 → Σ = 5 × 0.0525 × 1 = 0.2625
- **食物 = 1 + 1.25 × 0.2625 = 1.33** —— 说明**低技能 + 单一低效食材几乎等于没效果**

## 6. 与本项目存档数据的对接方案

经实服存档测绘（Isl，253 个自定义食谱），**公式所需输入全部可离线取得**：

| 公式输入 | 存档字段 | **item.gz 是否已输出** | 输出字段名 / 实测样本 |
|---|---|---|---|
| `CraftingSpeed` | **`CraftingSkill`**（Float） | ✅ **已输出** | `craftingSkill`（小数：`12.0` = 1200%；`-1` = 无） |
| 食材清单 + 数量 | `CustomResourceRequirements`（Array, 101 B） | ❌ **不输出** | 前端用**自有命令**直接拉取 |
| 菜 / 饮 判定 | `bIsFoodRecipe`（**存档未序列化**） | ❌ **不输出** | 用**类名**判定：`PrimalItemCustomFoodRecipe_*` = 菜、`CustomDrinkRecipe_*` = 饮 |
| 食谱标记 | `bIsCustomRecipe`（**存档未序列化**） | ❌ 不输出 | 同上，类名即可（前端自行判断） |
| 显示名 / 描述 / 图标色 | `CustomItemName` / `CustomItemDescription` / `CustomColors` / `ItemColorID` | ✅ 已输出（`customName`） | Str / Array / Int16 |

> ⚠️ **实测更正（2026-09-18）**：`bIsFoodRecipe` 与 `bIsCustomRecipe` **在存档里根本不存在** —— UE 不序列化值为 `false` 的 bool 属性（对全部 253 个食谱做完整属性 tag dump，属性清单里没有这两个名字）。因此**不输出这两个字段**；判「菜 / 饮」直接用类名即可（游戏本身也是这么区分的）。

**落地步骤建议**

1. 食材清单（类名 + 数量）由**前端现有命令**直接拉取，item.gz 不重复输出
2. 用 §4 系数表把食材基类名映射到五项系数（需要一张 **类名 → 系数** 字典）
3. 直接读 item.gz 的 **`craftingSkill`** 代入 §2.1 / §2.2
4. 用**类名**决定输出「食物」或「水」：`PrimalItemCustomFoodRecipe_*` → 食物生效；`CustomDrinkRecipe_*` → 水生效（另一项置 0）
5. 前端展示时标注为**推算值**，与游戏内 tooltip 可能有个位数偏差

## 7. 风险与待验证项（重要）

| # | 风险 | 说明 |
|---|---|---|
| 1 | **版本差异** | 公式出自 **ASE v224** 的 Wiki；ASA 是否沿用同一系数**未经验证** |
| 2 | **蛋 / 粪 系数非固定** | 与实体重量绑定，Wiki 数值为估算 |
| 3 | **技能上限差异（已实测坐实）** | 实测 253 个食谱的 `craftingSkill` 最高达 **20.9（2090%）**，远超 Wiki 所述 1590% 上限；分布为 `20.9`×114、`18.4`×28、`11.1`×31、`19.9`×16、`14.1`×10、`9.3`×10、`12.0`×6 … → **ASA 的实际上限/加成确切值与 ASE 不同，需按本服实测范围校准** |
| 4 | **食材清单结构未细化** | item.gz **不输出**该字段（前端用命令拉取）；若后续要离线计算，仍需逐字段确认 `CustomResourceRequirements` 的数组布局 |
| 5 | **系数表未覆盖全部食材** | Wiki 表只列常用食材；MOD/新图食材（如 ASA 新增浆果 Cianberry / Magenberry / Verdberry）**暂无系数** |
| 6 | **辣椒酱等 Buff 的影响时机** | 公式只考虑"制作食谱那刻"的技能快照，若服务器有倍率插件需另行叠加 |
| 7 | **"14.88x" 口径** | Wiki 提到最大技能可产出 14.88 倍，与本文按公式算出的 15.88 倍（对 100% 基准）**存在偏差**，Wiki 该数字来源未标注推导过程，**建议以公式为准并以实机对拍校准** |
