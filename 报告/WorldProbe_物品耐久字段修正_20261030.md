## 1. 一句话

`durabilityPct` 是**新增字段**，表示当前耐久比例（0~1）；旧的 `durability` 恒为 0，**请改用新字段**。

---

## 2. 问题（修复前）

前端反馈：**武器当前耐久全部为 0**。

修复前实测 Isl：24,184 条物品 / 2,258 件武器，`durability != 0` 的数量 = **0**。

---

## 3. 根因

exe 一直解析的字段是 `ItemDurability`，但存档里武器/护甲/工具**根本没有这个属性**。

真实字段是 `SavedDurability`（`FloatProperty`，4 字节），已用存档实际 dump 确证：

| 属性 | 类型 | 是否存在 |
|---|---|---|
| `SavedDurability` | `FloatProperty` size=4 | 存在 |
| `ItemDurability` | — | **不存在** |

⇒ 所以 `durability` 恒为 0，属**解析字段名错误**，不是数据缺失。

---

## 4. ⚠️ 它是「比例」，不是「绝对值」

`SavedDurability` 取值范围 **0 ~ 1（1.0 = 满耐久）**，实测样本：

```
1.0     0.992    0.9788    0.9968    0.9955
0.9885  0.867    0.7158    0.5446    0.3906    0.1331
```

存档里**没有「最大耐久」字段**（上限由物品类默认值决定，不随物品存档），
所以**无法还原成 1234/2000 这种绝对值**，只能给百分比。

---

## 5. 新字段（前端改用这个）

```json
{
  "class": "PrimalItem_WeaponMetalPick_C_2146590424",
  "kind": "weapon",
  "durability": 0,              // 旧字段，恒 0，请忽略
  "durabilityPct": 0.8670,      // 新字段：当前耐久比例
  "isBlueprint": 0
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `durabilityPct` | number | 当前耐久比例（0~1）；**`-1` = 该物品无耐久属性** |
| `durability` | int | 旧字段，**保留但不生效**（源属性不存在），勿使用 |

三条判定规则：

| 值 | 含义 | 建议展示 |
|---|---|---|
| `>= 0` | 真实耐久比例 | `(pct*100).toFixed(1) + "%"` |
| `-1` | 该物品**没有**耐久属性 | `—`（不要渲染成 0%）|
| 键不存在 | 极旧数据（未重跑） | 同 `-1` 处理 |

## 7. 前端改法

```js
function durText(pct) {
  if (pct === undefined || pct === null || pct < 0) return "—";   // -1 或缺失
  return (Math.min(1, pct) * 100).toFixed(1) + "%";               // 显示截断到 100%
}

function durColor(pct) {
  if (pct === undefined || pct === null || pct < 0) return "#888";
  if (pct < 0.2) return "#f87171";   // 低
  if (pct < 0.5) return "#fb923c";   // 中
  return "#4ade80";                  // 高
}

// 进度条宽度：截断；数值展示：不截断（见 §8 第 1 条）
const barW = pct < 0 ? 0 : Math.min(1, pct) * 100 + "%";
```

---

## 8. 四个必须注意的点

1. **`max > 1` 确实存在（实测最高 1.3000 / Los）** —— 部分物品耐久可超基准值。
   进度条请 `Math.min(1, pct)` 截断显示，但**数值本身不要截断**（否则会误报成 100%）。
2. **`-1` 表示「无此属性」，不是「0 耐久」** —— 别渲染成 0%，会让人以为装备全坏了。
3. **蓝图（`isBlueprint = 1`）耐久通常为 1.0**（图纸无真实耐久），展示时可跳过或单独标注。
4. 旧字段 `durability` 仍会出现在 JSON 里但**恒为 0**，若前端还在读它，属于 bug，请切换。
