# 野生恐龙检索：南巨类名与「腐化」判定口径（2026-11-01 实测定稿）

> 数据来源：实服只读探测 `TransferIdentityFix.WorldProbe scan`（Ext :32324、Isl :32320）+ 游戏本地化表 + ASB 物种库 + 真实驯服数据，四方一致。
> 结论取代此前"南巨=Giganotosaurus_Character_BP"的错误说法。

---

## 1. 南巨的真实类名

| 项目 | 值 |
|---|---|
| 南巨（Giganotosaurus）类名 | **`Gigant_Character_BP_C`** |
| 基线蓝图 | `Gigant_Character_BP_Base` |
| 误用写法 | ~~`Giganotosaurus_Character_BP_C`~~（游戏里**不存在**，搜出来恒为 0） |
| 易混对象 | `BigFoot_Character_BP_C` = 巨猿（Gigantopithecus），与 "Gigant" 无关 |

---

## 2. Ext 实测结果（:32324，`WorldProbe scan filter=Giga top=60`）

```json
"classes": [
  {"class": "Gigant_Character_BP_C",              "count": 88},
  {"class": "Gigantoraptor_Character_BP_C",       "count": 12},
  {"class": "Bone_Gigant_Character_BP_FE_C",      "count": 8},
  {"class": "GigantoraptorNest_C",                "count": 4},
  {"class": "Ghost_Gigantoraptor_Character_BP_FE_C","count": 3}
]
```

- 那 **88 只就是普通野生南巨**（`Gigant_Character_BP_C`），既不是腐化、也不是冒名
- **它们出现在"腐化区"只是位置**（生成/游荡在该区域），**与种类无关**
- Ext 当前**没有任何** `Giganotosaurus_*` 类（该拼写不存在）

---

## 3. 「腐化」在类名上的真实编码

腐化生物有**独立类名**，规则为 `<本体类名>_Corrupt_C`。Ext 实测 13 类（`filter=Corrupt_C`）：

| 类名 | 数量 | | 类名 | 数量 |
|---|---:|---|---|---:|
| `Dilo_Character_BP_Corrupt_C` | 951 | | `Wyvern_Character_BP_Fire_Corrupt_C` | 49 |
| `Ptero_Character_BP_Corrupt_C` | 613 | | `Arthro_Character_BP_Corrupt_C` | 40 |
| `Raptor_Character_BP_Corrupt_C` | 263 | | `Spino_Character_BP_Corrupt_C` | 36 |
| `Stego_Character_BP_Corrupt_C` | 234 | | `Paracer_Character_BP_Corrupt_C` | 33 |
| `Trike_Character_BP_Corrupt_C` | 206 | | `RockDrake_Character_BP_Corrupt_C` | 14 |
| `Carno_Character_BP_Corrupt_C` | 76 | | `Xenomorph_Character_BP_Male_Tamed_Corrupt_C` | 7 |
| `Chalico_Character_BP_Corrupt_C` | 66 | | `BP_Obelisk_C_Corrupted_C`（方尖碑，非生物） | 1 |

**列表中没有 `Gigant_Character_BP_Corrupt_C`** ⇒ Ext 当前没有腐化南巨。

---

## 4. 前端检索口径（按此改）

| 目标 | 正确类名 / 检索词 | 期望结果（Ext 现网） |
|---|---|---|
| 普通野生南巨 | `Gigant_Character_BP` | 88 只 ✅ |
| 腐化南巨 | `Gigant_Character_BP_Corrupt` | **0 只**（该服没有腐化南巨，返回 0 是正确行为） |
| 其它腐化种 | `<本体>_Character_BP_Corrupt`，如 `Raptor_Character_BP_Corrupt` | 见上表 |

> ⚠️ 不要用「坐标是否落在腐化区」判定腐化 —— 那只是生成区域，88 只普通南巨就在腐化区里。

---

## 5. 一句话总结

**南巨 = `Gigant_Character_BP_C`；腐化种 = 类名带 `_Corrupt_C` 的独立类；Ext 的 88 只南巨是普通野生种，只是站在腐化区。**
