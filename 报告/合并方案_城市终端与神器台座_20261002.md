## 二、实现设计（纯前端渲染层聚合；不动词典 / localStorage 结构 / 后端）

### 1. 新增配置常量 `LB_PUBFAC_MERGE`
```js
var LB_PUBFAC_MERGE = [
  { key:'__CT__', zh:'城市终端',   en:'City Terminal',    icon:'94034504c2aa', re:/^CityTerminal/ },
  { key:'__PD__', zh:'上古神器台座', en:'Artifact Pedestal', icon:'<待定-你选>',   re:/^ArtifactCrate_/ }   // 注意：正则带下划线，天然不命中基础类 ArtifactCrate
];
```

### 2. 渲染（`lbPubFacRender`）
- `ks` 过滤阶段：被任一 `re` 命中的成员键**从常规列表剔除**；随后**插入合并键**（排序位＝原组位置：终端组首 / 台座组首）。
- 合并格内容：
  - **数量** = 成员 `sv` 计数合计（如城市终端 27、台座合计）
  - **tooltip** = `中文名 | 英文名 | 成员分布（普通×17/废土×5/沙漠×4/雪地×1）| 点击查看位置点位`（**不显示内部键**，遵循 9-30 教训）
  - **data-pos-key** = 合并键（`__CT__` / `__PD__`），点击走新分支
- `_pk` 排序：合并键权重沿用原组（终端=1；台座=8 区）。

### 3. 点击（`lbFacPosOpen` 新增 `mg` 分支）
- 合并键（`__` 前缀）→ 遍历成员键 → 读 `LB._pubFac[成员].xyz`（v4232 起已有）→ **合并 `dots[服]`（去重）** → `lbFacPosRender(name, dots, {}, [], {}, '', {})`（同现状区样式）。
- 城市终端：4 类点位混显（约 27 点/全服）；台座：21 类点位混显。
- **只读本地坐标**（与现状区一致，无网络查询）✓。
