## 1. 背景与方法论对齐

ARK 繁育标准路线：**① 属性集中 → ② 等级压缩 → ③ 属性变异 → ④ 颜色繁育 → ⑤ 最终融合**；核心资产是长期维护的「血统/种龙库」（属性线、颜色线分开管理，不混垃圾变异）。

附件 `报告/繁育方向`（四方向 + 负变异计数说明）→ 功能需求映射：

| 方法论 | 需要工具化能力 |
|---|---|
| 属性集中（组底板） | 把选中的公/母「留档成一组」，看缺哪条属性 |
| 等级压缩（腾空间） | 氧/食/速应清零——标出待压缩项 + 等级估算 |
| 属性变异（分线堆叠） | 一条线累积变异代数统计，♂/♀ 分开；提示 20/20 上限风险 |
| **负变异计数（家谱溢出）** | **识别随机突变计数 <0 的龙 = 负变异血统（不触发 20/20 上限，可继续叠）→ 卡/看板标金徽章；主流玩法提示：高变异公 × 0 变异母大队** |
| 颜色繁育（做外观） | 6 region 色板 + Hex + 纯色/主题色检测 |
| 血统库维护 | 种龙收藏 + 路线分组（属性线/颜色线分开） |

> 负变异计数 ≠ 压垃圾属性：方舟变异规则是任一侧计数达 **20/20** 后几乎不再出新变异。负变异计数是 ASE 早期遗传计算的整数溢出 BUG——家谱数字溢出成负数（如 −10000），游戏只判断“是否 >20”，负数 <20 被当成“还很年轻”，于是**该血统可无限继续叠变异**（老官方服收藏级种龙价值所在）。普通玩家不必追，主流仍是：**属性集中 → 单线变异 → 多线合并 → 等级压缩**，配“高变异公 × 海量 0 变异母”来规避 20 上限。

## 3. 总体设计

### 3.1 入口与载体（已确认）
繁育栏新增按钮 **「🧬 路线库」** → 打开独立浮窗（复用 `#lbBreedOverlay` 交互模式，点遮罩/✕ 关闭）。浮窗内 Tab 两级：**线列表 ↔ 单线详情**。

### 3.2 数据模型（纯前端，localStorage `lb_breed_lines`）

```jsonc
{
  "lines": [
    {
      "id": "l_<ts>",
      "name": "板板·血线",          // 用户命名
      "type": "line",               // line=属性线 / color=颜色线 / mix=混合
      "goal": "HP 60 / 攻 60",      // 目标备注（可选）
      "created": 1788350000000,
      "members": [                  // 只存定位键，数据实时反查缓存 rec
        { "sv":"Isl", "id1":70525221, "id2":8393953 }
      ]
    }
  ]
}
```

- 实时反查：成员卡渲染用 `lbWatchFindRec` 同款思路（按 sv+id1 反查 `LB._cache.data.recs`），不在线/已成年等异常降级显示占位。
- 线内成员允许♂♀混存；一条线可收藏任意生物（含球内/放出/野生种公）。
- 上限：线数 ≤50、每线成员 ≤40（防 localStorage 膨胀与浮窗渲染过载）。

### 3.3 入线交互
- 生物卡（主列表/候选/搜ID结果）新增小按钮 **「📥 入库」**（样式同 `lb-id-btn` 一族，右上/右下角，仅玩家可见的生物显示——与改名按钮同判定 `_canRename`）。
- 点击 → 弹出「加入路线库」浮窗：选已有线 / 快速新建线（输入名+类型）→ 加入并 toast。
- 卡上已有「入库」标记态（该卡在≥1条线中 → 按钮高亮）。

### 3.4 单线详情「路径看板」（核心）

打开一条线，分区块（对应方法论 ①-⑤ + 负变异计数识别）：

**A. 成员卡区**：线内所有成员以 `lbDinoHTML` 完整卡横排/纵列展示（含色带/变异/属性），卡右上角可移出。

**B. 属性集中合并矩阵**
- 表格：行=成员，列=6 主项（血0/耐1/氧3/食4/重7/攻8）+ 等级 + ♂/♀；
- 末行 = **线内最高值**（= 理论拼装底板的每项上限），逐列高亮"当前最高"所属成员；
- 目的：一眼看出要补哪条属性、从哪个成员来。

**C. 等级压缩提示**
- 对每个成员标出"垃圾属性"当前点数：氧(3)/食(4)/速(9) 三项（`statPoints` 取数）；
- `点数>0` → 橙色徽章「待清零」；全 0 → 绿 ✓「已压缩」；
- 线级辅助：各成员 `Σ全部 12 项点数` → 出生等级估算（卡片 `level` 兜底），用于对比"未压缩 vs 已压缩"等级差；
- 线级提示：若氧/食/速尚有 `点数>0` 的成员 → 提示"先压线再叠变异，省等级留变异空间"。

**D. 变异代数汇总 & 变异计数（v3 含负变异计数）**
- 表格按属性（血耐晕氧食水温重攻速抗制 12 项）统计线内：
  - ♂ 最大代数、♀ 最大代数、是否有跨线混配风险（同一属性存在 2 条以上不同代数路径 → 提示"断代对齐"）；
- **变异计数（家谱 counter）**：每成员显示 父系/母系计数（`randomMutationsMale`/`randomMutationsFemale`）：
  - 任一侧 `≥20` → 橙标「父系 20/20 近上限」/「母系 20/20 近上限」；两侧都 `≥20` → 红标「基本报废」；
  - 任一侧 `<0` → **金标「负变异血统 ∞」（不触发 20 上限，可继续叠）**；
- 线级主流做法提示："高变异公 × 0 变异母大队"（公任一侧高、母全 0 时最能延续）。

**E. 颜色 region 板**
- 每个成员显示 **6 个 region 色块 + Hex**（`colors` 逗号串 → `lbColorHex`；region 0-5 标注身体/背/腹/脚/纹/尾按物种提示，未知显示序号）；
- **纯色检测**：6 region 全同 → 徽章「全黑/全白/单色 X」；
- **主题预置检测**：黑+红+橙→🔥熔岩、白+蓝→❄冰霜、白+金→👑黄金（可配预设表，后续可扩展）；
- 颜色线（type=color）该区置顶。

**F. 变异空间（基于变异计数上限评估，v3 改写）**
- 每成员展示其父/母系计数 vs 20 上限（`20 − max(male,female)` 估算仍可叠代数；负计数成员显示 ∞ 不设限）；
- 线内若存在负变异血统成员 → 顶部金标"本线含负变异血统，可无限叠"；否则提示"注意任一侧 20/20 后需换 0 变异母续叠"。

## 4. 阶段 2（后续迭代，本次不实施）：配对后代模拟

- 线内选 1♂×1♀ → 弹「配对模拟」：
  - 每主属性按 ARK 遗传（55% 取父高 / 45% 取母低 + 变异 ±2 点叠加）模拟 **期望子代**（展示 6 主项+等级区间）；
  - 颜色按 region 独立 55% 遗传 → 子代颜色预览（逐 region 显示来自父/母/变异）；
  - 变异说明：纯父母代数差、可叠代数空间提示。
- 依赖：`statPoints`/`colors` 数据已具备；工程量主要在规则与 UI，单独迭代。

## 5. 技术要点 / 风险

- 复用关注未成年「存键 + 反查 rec」模式，避免 localStorage 存大快照（成员数据随主数据实时刷新）。
- 全部纯前端，**无后端改动**；离线可用；数据量小（≤50 线 × 40 成员键）。
- 浮窗性能：渲染按需（线详情懒渲染），成员卡复用 `lbDinoHTML`。
- 与现有繁育栏关系：路线库是"收藏层"，不干扰现有候选筛选逻辑；候选结果卡上的「入库」是主入口。
