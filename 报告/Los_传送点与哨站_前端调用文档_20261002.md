### 4.2 类名解析规则

```
MissionType_LC_Outpost_<Category>_<Scale>_<Tier>_C
```

| 段 | 取值 | 含义 |
|---|---|---|
| `<Category>` | `Attack_Training` / `Attack_Tame` / `Attack_Ranged` / `Attack_Industrial` / `Defend` / `ResourceCache` | 任务类型 |
| `<Scale>` | `Small` / `Medium` / `Large` / `City` | 规模（`City` = 城区大型） |
| `<Tier>` | `Alpha` / `Beta` / `Gamma` | **难度档** |

```js
const tier  = a.class.match(/_(Alpha|Beta|Gamma)_C$/)?.[1] || '';   // 难度
const scale = a.class.match(/_(Small|Medium|Large|City)_/)?.[1] || '';
const kind  = a.class.includes('ResourceCache') ? 'cache'
             : a.class.includes('_Defend_')     ? 'defend'
             : 'attack';
```

> ⚠️ **难度请从类名解析 `Tier`，不要依赖 `difficulty` 字段** ——
> 30 个任务点里 `difficulty` **只有 5 个**有值（都是 `medium`，且这 5 个的类名里恰好也带 `Medium`），其余 **25 个为空串**。
> 也就是说 `difficulty` **既不完整也不等义于 Tier**。
