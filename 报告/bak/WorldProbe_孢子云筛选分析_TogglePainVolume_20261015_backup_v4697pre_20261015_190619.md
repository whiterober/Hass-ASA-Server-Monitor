# 孢子云筛选分析 —— 266 个 `TogglePainVolume` 中哪些是「隐形孢子云」

> 输入：`Aberration_spore_clouds.json`（266 条）+ 玩家地图标记 8 处（`GameUserSettings.ini` 的 `SavedMinimapMarks`）
> 分析日：2026-10-15 ｜ 分析：本地坐标匹配 + 形态聚类 ｜ **未经逐一游戏内验证（8 处实测锚点除外）**

## 一、结论速览

**实锤**：玩家地图标记的 8 处孢子云，**全部**与 `TogglePainVolume` 的「紧凑组」咬合（水平距离 2~28m）。
⇒ 「一处孢子云」= **3~17 个体积拼成的一组**（体积是云的最小实现单位）。

**全图同类组 = 23 组**（100m 聚类，n≥3）：
- **8 组 = 玩家实测**（冰冻×4 蓝区 / 致幻×4 绿区）
- **15 组 = 同形候选**（玩家未标注，形态与实测一致，待验证）

**其余约 200 点**：
- 等距长排 38 点（间距 ~160m，全部贴地图外围高地）——疑似地表/边界类机制，**非孢子云**
- 孤立单点/双点约 65 点——形态与实测云不符，**倾向非云**（个别小云不能排除）

## 四、方法

1. **坐标换算**：`lon = x/8000 + 50`、`lat = y/8000 + 50`（dino 前端 Wikily 校准确认；⚠️ 原报告 `mapX/mapY` 用未校准估算，偏差大，勿用）
2. **排族剔除**：同 y/z（或 x/z）、n≥3、跨度 >150m 的线性序列 → 38 点
3. **聚类**：剩余 228 点按 100m 3D 邻接 union-find → 84 簇 → 取 n≥3 得 23 组
4. **锚点校验**：玩家 8 处地图标记逐一匹配（全部命中 n≥3 组）

- 本次仅 8 处实测锚点，**15 个候选组未经游戏内验证**
