## 三、Phase 1 设计（前端单侧，立即可实施）

### 1. 数据加载（新函数 `lbNotesLoad`）
- **复用 `lbFetchDataJson(base, gzUrl)`**（gz 解压/25s 超时/5xx 重试全套免费）
- URL：`DINO_JSON + abbr + '_notes.json.gz'`，10 服 `Promise.all` 并行
- **懒加载**：首次打开 `t:explorerchest` 浮窗时触发；**会话缓存** `LB._notes = { abbr: { eos: {notes:[], uc} } }`
- 容错：单服失败→该服不隐藏；全失败→全显示（console 记因，不弹错）

### 2. 玩家识别（纯复用）
- `LB.playerEos` 已登录 → 直接匹配 `players[].eos`
- 未登录（`LB._needLogin`）/ eos 缺失 / 文件内无此人 → **不隐藏**（全显示）

### 3. 组级判据（新函数 `lbNotesHiddenSet(abbr)`）
- 每图计算：
  - 点位侧：从**缓存全量** `dots[abbr]` 统计每 class 点数 `pn[class]`
  - 解锁侧：`LB._notes[abbr][myEos].notes[]` 按前缀计数 `un[person]`（映射表 `LB_NOTE_EOSMAP`：19 人物 + 图鉴，新增；与 `LB_NOTE_MAP` 互补）
  - `un[person] >= pn[class]` → 该 class 进**隐藏集** `LB._noteHideSet[abbr]`
- 返回 `Set`

### 4. 渲染过滤（**唯一侵入点，3 行**）
- **落点**：`lbFacPosPage()` 开头——`arr` 进 `dots` 循环前：
  ```js
  if(kind === 'explorerchest' && LB._noteHideSet && LB._noteHideSet[abbr] && LB._noteHideSet[abbr].has(cls)) skip
  ```
- **关键设计**：过滤在**渲染层**、`LB._facPosC` 缓存**保持全量** → **切换按钮零网络重渲染** ✓

### 5. 切换按钮（用户明确要求）
- 位置：`lbMapPagerRender` 的 **headBtns**（与关闭按钮同排，复用同款样式/交互）
- 文案：`🙈 仅未收` ↔ `👁 显示全部`（默认前者=隐藏已收齐组）
- 点击：翻转 `LB._noteHide`（全局与会话级）→ **复用 `lbFacPosRender(name, cache.dots, …)` 从缓存重渲染**（零网络）

### 6. 标题/图例联动（自动，无需改动）
- 点位数、图例 19 色计数均基于过滤后 `arr` → **自动联动** ✓
- 可选增强：标题后缀「（已隐藏 N 点）」

### 7. 复用清单（**非复制**，逐项交代）
| 复用对象 | 用途 | 改动量 |
