# Rag 火山：机制与查询口径说明（2026-10-12）

> 面向：前端（dino-import）
> 关系：本文**补充/修正** 2026-10-10 的《火山喷发状态查询_前端调用文档.md》，不替代它。
> 结论来源：实服只读探测（RCON `WorldProbe`，Rag :32326）+ 蓝图函数调用实测 + 官方 DevKit 资产核对。

---

## 一、一句话结论（先看这个）

1. **`TimeNextVolcanoEvent` 是"镜像字段"**：写它不会引发喷发（无玩家/有玩家都一样）⇒ **不可当作"下次喷发时间"的可信来源**。
2. **真正能开喷的是零参数函数 `StartVolcanoEvent`**（`callfunc fn=StartVolcanoEvent` 实测：`VolcanoActive=1`、`WorldVolcanicIntensity` 0→1.0、时长 120 s ✓）。
3. **火山间隔真实值 = (5000, 15000) 秒 = 1.39 ~ 4.17 小时**（≈1.7~5.2 游戏日）⇒ 与 wiki「once every few in-game days」吻合 ⇒ **"等很久不喷"是正常现象，不是探测失败**。
4. **`ForceStartVolcano` 只是把 `TimeNextVolcanoEvent` 写成"即将到期"**，并不会喷 ⇒ 旧文档"改字段即可到点触发"的措辞需修正。

## 二、字段口径（`actor filter=VolcanoManager props=1`）

| 字段 | 可信度 | 语义 / 陷阱 |
|---|---|---|
| `VolcanoActive` | ✅ 可信（0/1） | 是否处于喷发中 |
| `VolcanoStarting` / `VolcanoEnding` | ✅ 可信（0/1 阶段位） | 起爆/收尾阶段（与已验证有效的 `bInWeatherTransition` 同构） |
| `WorldVolcanicIntensity` | ✅ 可信（0~1+） | 喷发强度；实测喷发时 0→1.0 |
| `LocalVolcanicIntensity` | ✅ 可信 | 局部强度（玩家附近） |
| `TimeVolcanoEventStarted` / `TimeVolcanoEventEnds` | ✅ 可信（世界秒） | 实测 `Ends − Started = 120 s` |
| `VolcanoEventLength` | ✅ 可信 = **120**（秒） | 事件时长 |
| `TimeNextVolcanoEvent` | ⚠️ **镜像/仅显示** | 写入不生效；**不要用它给前端算"下次喷发倒计时"** |
| `VolcanoIntervalMinMax` | ⚠️ **8 字节结构（两个 float32）** | 真实值 **(5000, 15000)**；若按 double 直读会得到 `1.67e+31` 垃圾值（v102 起插件已按 hex 双 f32 解码） |
| `ProjShotFrequency` | ⚠️ 同上 | 真实值 **(0.5, 5)**（旧显示 2048 亦为误读） |
| `WorldVolcanicIntensityToConsiderLavaActive` | ✅ = 0.75 | 达到该强度即视为"岩浆活跃" |
| `WorldVolcanicIntensityToLaunchProj` | ✅ = 0.9 | 达到该强度开始抛射 |

## 三、前端建议判据（三态）

| 状态 | 判据（建议） |
|---|---|
| **喷发中** | `VolcanoActive == 1`（或 `VolcanoStarting == 1`）—— 最稳，实测可靠 |
| **喷发即将开始** | 无可靠字段！`TimeNextVolcanoEvent` 不可用 ⇒ 若要做"预告"，只能用**历史间隔统计**（1.39~4.17 h 区间）作估算 |
| **喷发已结束** | `VolcanoActive == 0` 且 `TimeVolcanoEventEnds > 0`（配合 `endedAt` 口径，见 §五） |

---

## 四、触发入口（本插件可提供）

- **`callfunc fn=StartVolcanoEvent apply=1`**（零参数，`filter=VolcanoManager`）
  - 实测：`applied=1`、零错误、`VolcanoActive=1`、强度爬升、时长 120 s ✓
  - ⚠️ **副作用**：绕过游戏自身的事件序列 ⇒ **没有东西负责"到时收尾/重排下次"** ⇒ 强制开喷后，下一次自然喷发可能不会自动安排（需再手动 `ForceStartVolcano`/`EndVolcanoEvent` 或重启）
- `ForceStartVolcano`：仅把 `TimeNextVolcanoEvent` 写成"即将到期/过去值"，**不喷** ⇒ 不要用它做触发

---

## 五、与"天气历史"同一套时间口径（重要）

- 火山"结束时刻"此前只在**天气命令被调用时**判定、并用**查询时刻**当结束时间 ⇒ 误差 = 距上次轮询的间隔（实测 Ext 早 **414 s**、Rag 差 **2167 s**）
- **已列入修复**：把结束检测纳入插件 **5 秒自检**，且 `endedAt` 与天气历史 `recent[]` **同源**（优先游戏戳 `atEarliest=0`，否则观测窗口）⇒ 修好后误差 ≤5 s
- 前端在此修复上线前，请把火山"结束时间"当作**粗值**（±轮询间隔）

## 六、对 2026-10-10 旧文档的修正点

| 旧表述 | 修正 |
|---|---|
| "改 `TimeNextVolcanoEvent` 即可到点触发"（§3.12(b)） | ❌ 不成立；该字段是镜像。真入口是 `StartVolcanoEvent` |
| 用 `VolcanoIntervalMinMax` 推算下次喷发 | ❌ 先按双 f32 解码再用；且它只给**区间**，不能给"下次时刻" |
| 函数表未列 `StartVolcanoEvent` | ✅ 新增："真·开喷"入口（零参数，实测有效） |
| `worldTime` 相关结论 | 见 §五 统一口径 |
