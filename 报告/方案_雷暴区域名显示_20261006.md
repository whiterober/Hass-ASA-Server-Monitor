## 1. 需求与现状

**需求（用户口径）**：雷暴要能显示**生效区域名称**。

| 项 | 现状（v4364） |
|---|---|
| 雷暴判定 | `wxSemantics.enumIndices.currWeatherName` 剥后缀 == `ElectricalStorm`（v4344，与对接文档推荐一致） |
| 雷暴显示 | 天气图全图紫渐变覆盖层 + 右上角角标「⚡ 全图雷暴」（**无区域名**） |
| 区域名字段 | 响应里已有 `electricalStorm.regionNameProbe`（实测键在；雷暴中 = `"Center"`，文档 §1.10） |

> 文档定论：UDS 雷暴**没有几何边界数据**（不画区域圈）；但**区域名可读**（`regionNameProbe.asString`，必须走 `scopeProbe` 版本）；数字 `region` 滞后约 9 分钟，**不采用**。

---

## 2. 数据源与取数

- **路径**：前端 `LB._wx.data`（= `/api/worldprobe_weather` 响应）→ `wxSemantics.electricalStorm.regionNameProbe.asString`
- **时序**：仅雷暴激活期间有值（无雷暴时槽内全 0 / `asString` 空）
- **兼容**：`regionNameProbe` 理论上为对象（含 `asString` / `num` 等；具体 JSON 结构以真实雷暴响应为准），解析函数做双兼容（string 或 `.asString`）
- **净化**：显示前做一次字符白名单过滤（`[A-Za-z0-9_\- ]`），防异常字符上屏

---

## 3. 显示设计（已定：角标 + 面板 两处）

| # | 位置 | 文案规则 |
|---|---|---|
| 1 | 天气图右上角**角标** | 有区域名：`⚡ 全图雷暴 · 区域：Center`；无区域名：保持 `⚡ 全图雷暴`（不变） |
| 2 | 面板**「天气事件」卡**（Sco/uds） | 雷暴激活且区域名可读时，副行追加 `· 区域：Center`（副行原为「上一个：X」；为空时直接显示「区域：Center」） |
| 3 | 无雷暴 / 读不出 | **完全不显示**「区域：」字样（零残留、零降级干扰） |

> 措辞说明：「全图雷暴」保留（几何边界无数据的既有口径），区域名作为补充信息 —— 与文档「报区域名而非数字」一致。

## 4. 实现细节（dino-import.html）

### 4.1 新增工具函数（放 `lbWxStormOn` 附近）

```js
// v4365（用户口径）：雷暴生效区域名（regionNameProbe.asString；无雷暴=空串）
function lbWxEsRegion(j){
  try{
    var es = j && j.wxSemantics && j.wxSemantics.electricalStorm;
    if(!es) return '';
    var rp = es.regionNameProbe;
    var s = (typeof rp === 'string') ? rp : String((rp && rp.asString) || '');
    s = s.replace(/[^A-Za-z0-9_\- ]/g, '').trim();   // 白名单净化
    return s;
  }catch(e){ return ''; }
}
```

### 4.2 角标扩展（`lbWxStormOverlay` 内 badges 段，约 L21471）

```js
var _esRn = lbWxEsRegion(LB._wx.data);   // v4365：雷暴区域名（可空）
badges += '<div style="...">\u26A1 全图雷暴' + (_esRn ? (' · 区域：' + _esRn) : '') + '</div>';
```

### 4.3 面板扩展（uds「天气事件」卡副行，约 L21818）

```js
// v4365：雷暴激活时副行追加区域名
if(lbWxBase(wcn) === 'ElectricalStorm'){
  var _pRn = lbWxEsRegion(j);
  if(_pRn) wsub = wsub ? (wsub + ' · 区域：' + _pRn) : ('区域：' + _pRn);
}
```
