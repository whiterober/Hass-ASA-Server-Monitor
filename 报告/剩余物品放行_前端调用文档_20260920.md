| 项 | 值 |
|---|---|
| 文档版本 | v1.0 |
| 发布日 | 2026-09-20 |
| 对应程序 | `ark_save_reader.exe` = **1,549,312 B** |

## 一、变更概要

本轮把此前**静默丢弃**的多类真实物品放行进入 `items[]`，同时按用户口径继续排除**皮肤**与**设施印痕蓝图**。

`ItemGzType()` 新增 4 个放行分支（均在 `bIsBlueprint` 判定**之后**，因此 bp=1 的印痕仍走 `blueprint` 桶并被门控丢弃）：

| 新增 kind | class 族 | Isl 实测 |
|---|---|---:|
| `structure` | `PrimalItemStructure_*`（可放置建筑道具，bp=0） | **1,036** |
| `attachment` | `PrimalItemWeaponAttachment_*`（瞄准镜 / 消音器 / 激光 / 手电） | **100** |
| `tek` | `PrimalItem_Tek*`（bp=0） | **26** |
| `other` | `KindOf()` 无法归类的真实物品（见第三章） | **632** |

> 注：`kind="other"` **不是新 kind**（原本就存在），本轮只是让更多属于该 kind 的物品进入 `items[]`。

## 三、接口影响

### 3.1 `kind` 取值全集（前端枚举请更新）

`resource` · `ammo` · `structure` · `consumable` · `armor` · `saddle` · `attachment` · `weapon` · `tek` · `trait` · `trophy` · `tribute` · `other` · `geneGun`

> **`structure` 现在是"有数据"的 kind**（此前只会出现在 `facilities[]` 场景，`items[]` 中恒为 0 条）。

### 3.2 `type` 桶变化

| type | 变化 |
|---|---|
| `blueprint` | **无变化**（印痕仍排除，Isl 恒为 2303） |
| `ammo` / `resource` / `consumable` | **无变化** |
| `item` | **收录范围扩大**：接入 `structure` / `attachment` / `tek` / `other` 四类真实物品 |

**没有新增 `type` 桶**，`counts` 对象结构不变（仍是 `blueprint/ammo/resource/item/consumable` 五个键），前端无需改解析。

### 3.3 前端可能需要注意

- `item` 桶中将出现 `kind="structure"`（建筑道具）—— 若前端此前假设"`item` 桶 = 装备/工具"，需按 `kind` 再区分。
- `item` 桶中将出现更多 `kind="other"` 条目（632 条新增）。

## 四、仍不收录的内容（保持排除）

| 类别 | class 族 | Isl 数量 | 原因 |
|---|---|---:|---|
| 玩偶/外观皮肤 | `PrimalItemSkin_*`（ChibiDino 等 497 类） | **3,888** | 用户口径：皮肤不放行 |
| **服装皮肤包** | `PrimalItemCostume_*`（AAA SkinPack 系列） | **714**（635 在玩家背包） | 属皮肤家族，同口径排除 |
| 设施印痕缓存蓝图 | 未定级 `blueprint`（AnvilBench 2690 / LibraryStorage 672 / TekReplicator 276 / Fabricator 119…） | **12,367** | 各制造设施"我能造什么"的记账表，纯噪声 |
| 受精蛋 / 胚胎 | `PrimalItemConsumable_Egg*_Fertilized` / `_Embryo` | 1,066 | 已有 `eggs` 专用通道，避免重复 |
| 建筑印痕 | `PrimalItemStructure_*` 且 `isBlueprint=1` | 6,059 | 同印痕口径 |

> ⚠️ 因此 **`kind="other"` 与 `kind="structure"` 的条目数不等于"世界里的全部该类物品"**，只代表**真实持有**（bp=0）的部分。

## 七、前端适配建议

1. **`item` 桶不再等同于"装备"** —— 展示"装备/物品"列表时建议按 `kind` 过滤，或显式排除 `kind == "structure"`（建筑道具通常单独归类）。
2. **建筑道具**（`kind="structure"`）可直接用于"可放置建筑"清单；`class` 已是 `PrimalItemStructure_XXX` 形式，便于分组。
3. **`kind="other"` 内的车辆部件**（`PrimalItem_Car_*`）**带品质**（`rated/rating/qidx/stats`），可与其他装备一样展示品质。
4. **`kind="other"` 内的棺材快照**（`PrimalItem_CoffinSnapshot_*`）**带 `customName`**，可直接显示玩家自定义名称。
5. **不要**用"某类没出现 = 世界里没有"推断（印痕与皮肤被有意排除）。
6. `rated=0 / rating=-1` 表示**该物品无品质数据**或**为原始（Primitive）品质**——原始品质在存档中不落盘，属事实而非故障。

## 八、部署与生效

1. 用新 `ark_save_reader.exe`（**1,549,312 B**）覆盖实服 `\\SERVER\ARK Server\DinoData\ark_save_reader.exe`。
2. 重新生成各图输出后，`<Abbr>_item.json.gz` 即包含上述新增条目。
3. 旧的 `.gz` 不会自动重算，需要重跑解析。
