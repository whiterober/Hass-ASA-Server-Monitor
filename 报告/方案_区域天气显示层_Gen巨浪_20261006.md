## 1. 显示层规范（用户口径 ②）：主流程 vs 区域位

### 1.1 分区定义

| 分区 | 内容（整图级信息） | 说明 |
|---|---|---|
| **天气主流程** | 「天气事件」卡 / 头卡「概览」/ 变天倒计时 / 全图基准温度 / 强度卡（雾·风·温度偏移） | **只放整图级信息**；不放任何区域名、区域状态、区域概率 |
| **区域/图层位** | 热力图图层覆盖与**角标**、区域实时块（zones）、子图专属卡（Gen 五生态卡）、事件说明书行 | 区域性质天气的**唯一允许落位** |

### 1.2 区域性质天气落位表（现状 → 目标）

| 事件 | 性质 | 现状显示 | 目标（按本规范） |
|---|---|---|---|
| Sco 雷暴 | **区域**（`regionName`="Center"，无几何边界） | 图层覆盖 + 角标「⚡ 全图雷暴」；上轮方案曾拟加"面板卡副行" ❌ | 角标追加「· 区域：Center」；**不进**面板卡（见 §2 修订） |
| Sco 沙尘暴 | 全图尘墙扫掠 | 图层扫掠绘制 + 角标「🌀 沙尘暴·剩余」 | 维持 ✅（已在图层位） |
| Rag/Val/Los/Ast 沙尘暴 | **区域闸门**（触发卷内生效，§14） | 未接 | 图层/区域位（`active===1` 判据）——后续迭代 |
| Gen 巨浪 | **ocean 子图**（海况） | 未接 | **Gen ocean 生态卡**扩展（见 §3） |
| Isl/Cen 区域天气 | 区域（覆盖体积） | 区域实时块（已有） | 维持 ✅ |
| Gen 雪崩 / Abe 地震 | 区域随机事件 | 只显示规律文案 | 维持 ✅ |

### 1.3 红线（每次改面板时自检）

1. **禁止**把「区域」字样（区域名/区域状态/区域概率/水体参数）写入主流程卡（天气事件/概览/基准温度/强度卡）。
2. 区域信息一律进：**图层角标 → 区域块 → 子图专属卡**（按事件归属三者择一）。
3. 主流程卡出现"这次变化的**影响范围**"类信息时 → 移出到区域位。

## 3. Gen 巨浪（用户口径 ①：预警 + 详细信息）

### 3.1 数据源（文档 §16）

```
转移命令（插件侧）：TransferIdentityFix.WorldProbe wave        # v118+ 既有；响应约 1~2 KB
```

| 键 | 说明 |
|---|---|
| `verdict` | 插件派生海况结论（实测 `calm`）——**可直接上屏** |
| `weather.WaveState` | 海况数值 0=平静 … 1=满态（实测 0.35） |
| `weather.TimerNextWeather` − `worldTime` | **下次海况/天气变化倒计时**（实测 ≈1,327.6 s） |
| `weather.CurrentWeather` | ocean 子图天气名（可读，如 `ClearSky`） |
| `waterline.groups[]` | 4 组水体参数：`bakedOceanState / waveHeight / waveSteepness / bakedOceanSpeed / waterLevel / oceanTile` |
| 主海洋判定 | **`oceanTile` 最大者（60000）**= 主海洋主体（group1；浪高 47.25 / 陡度 7 / 速度 1.5） |
| `weather.bIsOcean` | =1 确证 ocean 系统 |

- ⚠️ `bakedOceanState` 是烘焙状态 ≠ 浪高；`waveHeight` 是参数上限，实际浪高按海况插值（文档 §16.3）。

### 3.2 预警设计（口径：倒计时 + 海况等级 + 详情）

| 层 | 内容 | 规则 |
|---|---|---|
| **预警** | `距变化 ≈ X 分`（`TimerNextWeather − worldTime`，30~60 s 刷新） | 时间口径 = `weather.worldTime`（世界钟推荐口径） |
| **等级** | `verdict` 中文化：`calm → 平静`（映射表 `LB_WAVE_ZH`；未知值回退原文） | 值域仅实测 calm，其余待补（见 §5） |
| **预警高亮（拟议）** | `WaveState ≥ 0.7` 时海况行橙色 + ⚠️（"浪情升"提醒） | 阈值文档未给，标为待实测校准；不阻塞首版 |
| **详细信息** | `海况 0.35 · 浪高 47.25 · 陡度 7 · 速度 1.5`（主海洋组） | 取自 `waterline.groups[]` 的 `oceanTile` 最大组 |

### 3.3 显示设计（区域位落位）

**落在 Gen 面板的 `ocean` 生态卡**（子图专属卡 = 允许落位）：

```
[🌊 海洋]                 ← label（不变）
[🧬 ClearSky ● 活跃]      ← main（不变）
[下一个：X / 正在变化]     ← sub（不变）
[海况：平静 · 距变化 ≈22 分]         ← 新增「预警行」（10px #a78bfa 系海况色）
[浪高 47.25 · 陡度 7 · 速度 1.5]      ← 新增「详情行」（10px #777；数据未就绪时整行不输出）
```

- 不新增独立"巨浪面板"（避免占主流程；如后续需深查另议）
- 非 ocean 子图 / 无 wave 数据 → 两行均不输出（零残留）

### 3.4 数据链与前置条件（重要）

| 环节 | 现状 | 动作 |
|---|---|---|
| 插件（dll） | `wave` 命令 v118+ 既有，**已可用** ✅ | 无 |
| **后端（dino_backend.py）** | ❌ **无 `/api/worldprobe_wave` 路由** | **需新增透传**（仿 `worldprobe_weather`：TTL 60 s 复用 + 同键并发合并；命令 `TransferIdentityFix.WorldProbe wave`） |
| 前端 | 无 wave 调用 | 新增 `lbWaveSync`（60 s 复用 / 单飞 + abort / 失败静默 / 开窗·切图钩子，与 `lbBioSync` 同范式）→ Gen ocean 卡扩展 |
| 前端兼容 | — | 路由未就绪时静默隐藏两行（无数据即不显示，零报错） |

### 3.5 验收（PW）

1. wave 就绪后：Gen 面板 ocean 卡出现「海况：… · 距变化 ≈…」与详情行；数值与证据响应一致（verdict / WaveState / 主海洋组）
2. 其它子图（arctic/bog/volcanic/月球）与其它 9 服：**无任何变化**（无「海况」字样残留）
3. 断源回归：路由未就绪 / 数据为空 → 两行不输出、无报错
