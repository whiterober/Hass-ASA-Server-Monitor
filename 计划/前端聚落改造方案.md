## 二、需求 4 点落地

### 需求1：离散特殊聚落归属全部落成员
- 聚落算法后，未落入任何聚落的**容器/球**归为 `scattered`（离散）
- **归属判定**：离散聚落内生物 → 归属于该生物部落的**全部落成员**（任何成员都算）

### 需求2：按聚落归属显示生物（当前按部落）
- **冠名 = 归属**：聚落的冠名成员（§8 规则算出）= 该聚落归属；生物归聚落即归冠名成员
- 归属判定（两分支）：
  - **非离散**：生物所属聚落的**冠名成员**含我的 pid → 我的
  - **离散**：生物 `tribeId` ∈ 我的部落 → 我的（全部落成员）
  - 无聚落数据 → 回退现有部落判定

### 需求3：繁育「我的/外部更高」标注聚落名
- `lbRenderBreedResult` 卡片 tag（`myTag`/`extTag`）追加聚落名

### 需求4：全面
- 列表容器标题标注聚落名
- 缓存/加载/边界/性能全链路

## 三、前端实现模块

### 模块A：数据归一化（已有字段）
- `addCryoRec` 已透传 `containerOwnerPid/EosId`（PID 改造完成）
- **需新增透传**：`containerX/containerY/containerZ`、`imprinterName`、`imprinterEosId`（rec 新字段）
- `_schemaVer` 升到 **5**

### 模块B：前端聚类算法（新函数 `lbBuildSettlements`）
```
输入：data.recs（或按 server 分组）
流程：
1. 按容器聚合：containerId → {x, y, type, tribeId, 球数, 印痕者集合}
2. 排除 player 背包容器 + 无坐标容器（x/y=0）
3. 按 tribeId 分组
4. 组内 DBSCAN（eps=6000，按容器 x/y 距离）
5. 输出：settlements[]（含 center/radius/容器数/球数/成员）+ scattered
6. 建立 dinoKey → {settlementId, distance} 映射
输出：data.settlements = { byServer, byDinoKey }
```
- **性能**：容器数 ~99/服，DBSCAN 很轻；只需对**当前可见服务器**计算
- **结果缓存**：计算结果存 `data._settlements`（会话内），服务器/数据变化时重算

### 模块C：归属判定升级（`lbIsMyRec`/`lbIsPlayerRec`）—— 严格按 §8 冠名规则
```
我的部落 = playerSet（现有，members[].pid 含 curPid）

判定（优先聚落）：
- rec 有 settlementId 且 ≠ scattered（非离散）：
    该聚落的冠名成员列表（§8.3 top_owners 前3名，含 pid）含我的 pid → 我的
    （聚落归属 = 冠名成员，冠名即归属）
- rec settlementId === scattered（离散）：
    rec.tribeId ∈ 我的部落 → 我的（离散归属全部落成员）
- 无聚落数据 → 回退部落判定（ownerTribeId/containerOwnerPid）
```

### 模块E：聚落冠名成员计算（严格按附件 §8）
```
§8.1 印痕者反查 pid（resolve_imprinter）：
  imprinterName 匹配 players.characterName
  + imprinterEosId 匹配 players.eosId
  → 综合定位 pid
  重名角色（"人类"×3）用 EOSID 区分；小号（同 EOS 多角色）用角色名区分

§8.2 仅限本部落（count_imprinter）：
  反查到 pid → 必须 ∈ 聚落所属部落 members[].pid 才计入
  未反查到 pid（如跨服缺失）→ 若印痕者名 ∈ 部落 members[].name 则计入（名字兜底）
  跨部落印痕者排除

§8.3 冠名（top_owners）：
  印痕者数量前 3 名 = 聚落成员（管理者）
  数量 < 第一名 5% 且绝对数量 < 50 条 → 剔除（不算成员）
  绝对数量 ≥ 50 条 → 不受 5% 比例约束（仍算成员）
  聚落名 = 成员名组合（如「嘎巴丸、人类」）
  无成员 → 回退 S 编号
```

> 🔴 **冠名 = 归属**：聚落的冠名成员列表即该聚落的归属集合。
> 判定「我的」= 我的 pid ∈ 聚落冠名成员（非离散）或 生物部落成员（离散）。

## 四、边界与兼容

| 场景 | 处理 |
|------|------|
| 无坐标容器（x/y=0）| 归离散或跳过 |
| player 背包容器 | 排除聚类（不算聚落）|
| 部分服务器无 cryo | 该服无聚落，回退部落 |
| 印痕者反查不到 pid | 用名字兜底（成员名匹配）|
| 跨服聚落 | 按 server 隔离计算 |
| 性能 | 容器级聚类（~99/服）极轻量；缓存计算结果 |
