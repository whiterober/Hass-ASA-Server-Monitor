# 地图坐标校准计划（ASA 生物速查页）

> 目标：校准各服务器地图图片（`img.whiterober.ccwu.cc/ASA/misc/{abbr}_s.jpg`，256×256）的坐标映射，使聚落/离散红点标注与实际位置精确对齐。
> 状态：**孤岛（Isl）已完成校准**（2026-08-12，v20260812-3）；其余 9 图待逐图校准。

---

## 一、背景与问题

前端在地图上按 UE 坐标标注聚落中心，换算公式（ARK 标准）：

```
lon = X / mult + shift
lat = Y / mult + shift
```

早期按「0~100 全图」归一化，导致两类系统性偏差：

1. **y 方向颠倒**：地图图片北在下/南在上，原公式把北放上方 → 标注上下颠倒。
2. **图片范围 ≠ 0~100 全图**：图片（如 `isl_s.jpg`）海洋占比仅 8.7%，实际只覆盖地图陆地主体（孤岛实测 lon 7.33~92.79 / lat 7.17~92.50，宽约 85.4），用 0~100 归一化 → 所有点「内缩一圈」（偏右/偏上）。

**核心结论**：每张图的 `lbWorldToPx` 必须按该图**实际覆盖的 lon/lat 范围**归一化，而非统一 0~100。

---

## 二、校准原理

图片坐标 ↔ 标准坐标近似**均匀缩放 + 平移**（线性映射）：

```
px(%) = a · lon + b
py(%) = c · lat + d
```

- 若 `a≈c`、`b≈d`（孤岛实测：a=1.1701、c=1.1720、b=-8.57、d=-8.41）→ 图片是正方形等比例缩放。
- 由 `px=0` 与 `px=100` 反推图片覆盖范围：
  ```
  lonMin = -b / a        lonMax = (100 - b) / a
  latMin = -d / c        latMax = (100 - d) / c
  ```
- 修正后归一化：
  ```
  px = (lon - lonMin) / (lonMax - lonMin) × 100
  py = (lat - latMin) / (latMax - latMin) × 100      # 北在下（lat 大 → 图下方）
  ```

**前提**：需要至少 2~3 个「已知标准坐标（lon/lat）+ 图上实际位置（%）」的点对。最佳地标 = **方尖碑**（Obelisk，每图固定 3 座，坐标可从 wiki/游戏内确认）。

---

## 三、详细步骤（每张图执行一遍）

### 第 1 步：准备地图图片 + 预览页
- 确认图片存在：`https://img.whiterober.ccwu.cc/ASA/misc/{abbr}_s.jpg`（浏览器 `<img>` 可直接加载，无需认证；Python 需带 UA）。
- 下载图片到 `tmp/_map.png`，生成点击定位预览页（参考 `tmp/_map_preview.html`，含 onclick 捕获点击百分比 + 标准坐标标注）。

### 第 2 步：确认该图方尖碑的「标准坐标」（lon/lat）
- 从 wiki 坐标表或游戏内确认三座方尖碑的 lat/lon（如孤岛 Red 79.8/17.4、Green 58.9/72.3、Blue 25.4/25.6）。
- 转换为 UE 坐标验证换算参数：`X = (lon - shift) × mult`、`Y = (lat - shift) × mult`（参数来自 `LB_MAP_INFO` 的 mult/shift）。

### 第 3 步：用户在预览页点击方尖碑实际位置
- 用户在图上依次点击三座方尖碑（或其熟悉的地标），记录页面显示的百分比：
  ```
  蓝 = (px1, py1)   红 = (px2, py2)   绿 = (px3, py3)
  ```
- 每图 3 个点最佳（均匀分布、拟合更稳）；至少 2 个（两轴各 2 个点）。

### 第 4 步：最小二乘拟合映射
- 输入点对：`(lon, px)`、`(lat, py)` 各 3 组。
- 拟合 `px = a·lon + b`、`py = c·lat + d`（脚本参考 `tmp/_fit_map.py`）。
- 校验残差：max 残差应 < 1%（否则点选不准，重新点击）。
- 反推图片范围：`lonMin = -b/a`、`lonMax = (100-b)/a`、`latMin = -d/c`、`latMax = (100-d)/c`。

### 第 5 步：配置 `LB_MAP_INFO`
在 `dino-import-new.html` 的 `LB_MAP_INFO` 中为该图加范围字段：

```js
// 范例（孤岛已配置）
Isl:{img:'isl_s', shift:50, mult:8000, lonMin:7.33, lonMax:92.79, latMin:7.17, latMax:92.50},
// 待校准图（暂用 0~100 默认）
Sco:{img:'sco_s', shift:50, mult:8000},
```

> `lbWorldToPx` 已支持范围：无 `lonMin/latMin` 配置时自动退化 0~100 全图。

### 第 6 步：校验 + 部署 + 浏览器验证
1. 语法校验：`node --check`（提取 script 到 `tmp/_chk.js`）。
2. 部署：`python tmp/_deploy_front.py`。
3. 浏览器验证（**必须带新时间戳强制刷新**，否则加载旧缓存）：
   ```
   location.href = location.pathname + '?t=' + Date.now()
   ```
4. 确认：聚落红点、离散点、方尖碑预测位置与实际对齐。

## 六、注意事项

1. **y 方向统一为「北在下」**：`py = (lat - latMin)/(latMax - latMin)×100`（lat 大=北→图下方），所有图一致。
2. **图片需带新时间戳强制刷新验证**：HA 本地资源有缓存，`reload` 可能加载旧版（检查 `LB_VERSION`）。
3. **方尖碑在存档中无实体**（世界固定对象），校准必须靠用户在图上的点击/描述，或 wiki 坐标。
4. **点选精度**：方尖碑在 256 小图上可能仅数像素，点击误差 ±2% 属正常；用 3 点拟合 + 残差校验，残差 >1% 时重选。
5. **Ast/Los mult 为估算值**（16250/3200），校准范围前建议先确认 mult/shift（可通过存档解析或游戏内锚点），避免与范围误差混淆。
6. **辅助脚本**（均在 `tmp/`）：`_map_preview.html`（点击定位预览）、`_fit_map.py`（最小二乘拟合）、`_map_contour.py` / `_analyze_map.py`（图片分析）、`_extract_js.py` + `_deploy_front.py`（校验部署）。
