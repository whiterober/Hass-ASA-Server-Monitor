---

## 设计原则

1. **零绝对定位**：所有无图纯数量徽章不使用 `position:absolute`
2. **唯一样式来源**：仅复用**描述行线性态有图时**的 `ic-qty` 徽章样式。板块级、IG 标题的徽章样式完全不同——不用
3. **位置跟随原图位**：数量显示在原本图片所在的位置（描述行/图标组标题行按 `image_position` 决定 before/after）
4. **板块级特殊处理**：板块纯数量显示在标题文字之后

## 详细方案

### 1. 描述行（desc_row）无图有量

**当前**：
```python
elif _qty:
    _dimg = '<span class="ic-img-qty">×{}</span>'.format(_qty)
```

**目标**：
```python
elif _qty:
    _dimg = '<span class="ic-qty" style="position:static">×{}</span>'.format(_qty)
```

- `position:static` 覆盖 `.ic-qty` 的 `position:absolute;right:0;bottom:0`
- 徽章出现在图片原本的位置，按 `image_position`（before/after 文字）流式排列
- 视觉样式（字号、粗细、背景色、圆角）与**描述行有图时的 `ic-qty`** 完全一致
- ⚠️ 不是板块级的 badge 样式，不是 IG 标题的 badge 样式，仅限描述行线性态有图 `ic-qty`

### 2. 图标组标题行（icon_group_title）无图有量

**目标**：同描述行逻辑，`ic-qty` + `position:static`，按 `title_icon_image_position` 决定位置。

### 3. 板块级（info_card_title）无图有量

**特殊处理**：板块级无图时，数量徽章显示在标题文字**之后**（after），而非图片位置。

**当前渲染结构**：
```
[图片/占位符] [标题文字]
```

**目标渲染结构**：
```
[标题文字] [×N 徽章]
```

徽章使用 `ic-qty` + `position:static`，放置在标题文字右侧。

### 4. CSS 清理

`build_lovelace.py` 中 `IC_CSS` 的 `.ic-img-qty` 定义可在确认无其它引用后删除。

## 位置规则总结

| 元素类型 | 无图有量显示位置 | 徽章样式来源 |
|---------|----------------|------------|
| 描述行 | 跟随 `image_position` | **描述行有图 `ic-qty`**（唯一来源） |
| 图标组标题行 | 跟随 `title_icon_image_position` | 同上 |
| 板块级 | 标题文字之后 | 同上 |
