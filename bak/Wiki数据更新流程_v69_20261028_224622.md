## 瘦身规则（必留 / 必删）

> v67 验证：156,242 B → **57,573 B（−63.2%）**；gzip 36,072 → **13,177 B**

### 必须保留（删了会功能缺失）

| 字段 | 体积 | 谁在用 |
|------|------|--------|
| `DATA[*].tabs` | 3,432 | `tabList()` 的唯一来源 |
| `tabHtml['1'].html` | 368 | `renderBreed()` 的 intro 文案（原型页 L1249） |
| `tabHtml[*].abils` | 3,991 | 技能 tab 视频列表（L1649 按 `_t._idx` 动态取） |

### 可以删除（渲染已全部自主化）

| 字段 | 体积 | 说明 |
|------|------|------|
| `tabHtml['2'..'6'].html` | 70,279 | 原始 tab HTML 缓存 |
| `DATA[*].abils` | 3,961 | `scope==='main'` 已无调用点 |
| `DATA[*].html` | 3,416 | 概览原始 HTML（`renderOverview()` 已接管） |
| `DATA[*].imgs/ms/raw_kb/tables/text_len/used` | ~90 | 抓取元信息 |

### 陷阱

- **`tabHtml` 的 key 是原始 tab 索引，会随 tab 拆分而变化**（例：v41 拆分「收割」后技能从 `'5'` 变 `'6'`）。
  → 一律用 `tabList()` 返回的 `_idx` 动态取，**禁硬编码**。
- **`pad:null` 是正常文案**（技能 tab 里讲数据格式的说明文字）。做「异常值检查」时只查 `undefined` / `NaN`，别把 `null` 算进去，否则误报。
- **改 `wiki_dex` 数据结构时必须同步改原型页**：本脚本只保证脚本侧 4 关通过，渲染侧要靠下面的实测清单。

## 常见更新场景对照表

| 场景 | 触发 | 要做的事 |
|------|------|---------|
| **R2 新增/更新图标** | 补了新图标到 `icons2_new.json` | 直接跑 `_wiki_dex_build.py` → 部署 |
| **ASB 升级（数值变化）** | 跑了 `流程\工具\update_asb.py` | 刷新 `tmp/_srv_values.json` → 跑重建 → 若 120 格 DIFF，先确认 wiki 侧是否也该变 → 部署 |
| **汉化表更新** | 跑了 `update_hanhua.py` | 若 `item_zh` 的 icon 名变了 → 跑重建 → 部署 |
| **wiki 重新抓取（新增物种）** | 抓到新物种的 `intro/tips/tabHtml.abils` | 手工补进 `wiki_dex.json` 的 `DATA` / `OVERVIEW` → 跑重建（会自动补 `stats`）→ 补基线 → 部署 |
| **只改文案（intro/tips）** | 无需重算数值 | 直接改 `wiki_dex.json` → 跑重建（会保留非计算字段）→ 部署 |
| **新增一个物种** | 从 3 个扩到更多 | ①`_wiki_dex_build.py` 的 `SPECIES` 加名 ②`STAT_IDX` 无需改 ③`_wiki_overview_baseline.json` 补该物种 8 行 ④ 原型页 `DATA`/`OVERVIEW` 就位 → 重建 → 部署 |

> **铁律**：任何情况下都**不要手工编辑 `wiki_dex.js`** —— 它由脚本生成（头部有注释声明）。要改就改 `wiki_dex.json` 或脚本配置区，然后重跑。

## 排错

| 症状 | 根因 | 处理 |
|------|------|------|
| `ABORT: 图标名 X 不在 icons2_new.json` | 孤儿图标（有图无物品引用）或图标名拼错 | 核对 `item_zh[key].icon` 与 `icons2_new.json` 的 `name` 是否逐字一致 |
| `ABORT: 属性表与基线不匹配` | ① `_srv_values.json` 换了版本 ② 公式被改 ③ 基线过期 | 先看 DIFF 明细：只有 1~2 格 → 多半是该物种特性；全表偏 → `fullStatsRaw` 布局变了 |
| `ABORT: tabHtml['1'].html 丢失` | 瘦身规则误删 | 检查 `TABHTML_KEEP_HTML` 是否含 `'1'` |
| 线上 `wiki_dex.json` 还是旧版本 | 边缘缓存 | 加 `?t=` + `cache:'no-store'` 复核；wrangler 已上传则等 1~2 分钟 |
| 原型页白屏 / tab 全空 | `wiki_dex.js` 语法错 或 数据结构被改坏 | `node --check wiki_dex.js`；查浏览器 pageError |
| `DATA[*].tabs` 丢了导致 tab 栏为空 | 瘦身误删 | `DATA_DROP` 里**不能**出现 `tabs` |
