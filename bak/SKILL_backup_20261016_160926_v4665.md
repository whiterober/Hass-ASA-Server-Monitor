# 新增生物固定工作流（newdino）

执行时：**建任务清单逐步勾选**；机械动作优先用 VS Code 任务「新生物:⓪~⑤」或 `流程\工具\` 脚本（AI 可直接跑脚本，等价）；判断/补缺由 AI 执行；**过闸标准不过不前进**。

## 先判类型（两条路径）

| 类型 | 特征 | 数据源 | 处理 |
|------|------|--------|------|
| 官方 DLC 生物 | PO/ArkKit 可查 | ASB values 可期待更新 | 常规链 |
| 模组生物（如 Astraeos） | PO/ASB 无记录 | **无 ASB 数据** | 浮窗归类：**统一收「预览」组**（`LB_TEST_EXTRA` + `LB_SPECIAL_NAMES` 必加；待 ASB 收录后移出正式归类） |

## 固定步骤（S0 前置 + 8 步）

| 步 | 动作 | 执行 | 过闸标准 |
|----|------|------|---------|
| S0 更新ASB（前置） | 任务「新生物:⓪ 更新ASB数据」或 `python 流程\工具\update_asb.py` | dev 分支 raw 直下 values.json / ASA-values.json，版本对比防降级；结果看 `_last_asb_update.txt` | 本地版本 ≥ 远端（跳过也算通过） |
| S1 登记 | 收生物名/来源提示 → 建任务清单 | manage todo | 清单齐 |
| S2 类名 | 任务「新生物:① 类名查询」或 `python 流程\工具\class_lookup.py <名>` | 权威链 PO→ASB→ShooterGame.json→wiki/存档→ArkKit 兜底 | 候选类名+证据（看 `流程\工具\_last_class_lookup.txt`；ASB 通道直出 blueprintPath 类名） |
| S3 体检 | 任务「新生物:② 一键体检」或 `python 流程\工具\preflight.py <类名>` | 七项状态表（物种库/翻译/图标/R2/缩略图/归属/导出） | 看 `流程\工具\_last_preflight.txt` 定位缺项 |
| S4 补缺+归类 | 按缺补：物种库/翻译/图标/归属/**浮窗归类** | 翻译=LB_SPECIAL_NAMES；图标=见「增量压图流程」；**归类：ASB 无数据→「预览」组（LB_TEST_EXTRA）；有数据→按情况**（默认正式区；偷蛋→LB_STEAL_EGG；载具→LB_OWNED_UNITS；渔获→LB_CATCHABLE_FISH；其余特殊→LB_EXTRA_FORCE；误隐藏→LB_TAMEABLE_FORCE） | 每项复检通过 + 浮窗可见、分组正确 |
| S5 前端改动 | 三表改动 + `LB_VERSION` 递增 | **改前备份**；数据文件更新必须递增版本（否则缓存）；含 emoji 的修改用 Python 写文件 | 语法校验 + diff 复查 |
| S6 部署 | 任务「新生物:⑤ 压图→部署 一键串」（= `_webp_incremental.py` + `tmp\_deploy_cf.py`） | 边缘缓存假报 → 浏览器 fetch no-store 复核 | 线上版本一致 |
| S7 实测 | 页面实测：搜索/图标/中文/归属/卡片 | 复用已开页面；PW 超时 10s 即判死，不重试 | 五项全过 |
| S8 沉淀 | 进度（`.copilot\进度\`）+ repo memory 案例 + `流程\新增生物流程.md` 案例区 | | 闭环 |

## 防漏清单（部署前逐项打勾）

- [ ] S0 已跑：ASB 已更新到最新（任务⓪ / 看 `_last_asb_update.txt`）
- [ ] 浮窗归类已做：新生物已入物种浮窗；ASB 无数据→「预览」组（LB_TEST_EXTRA + LB_SPECIAL_NAMES）；ASB 有数据→按情况归类
- [ ] 改动文件已备份（数据文件：先拉服务器版为基线，改前全量 diff）
- [ ] `LB_VERSION` 已递增（含数据文件更新时）
- [ ] `pwa/sw.js` CACHE 名已同步（若动 sw）
- [ ] 增量压图已跑
- [ ] `icons2.json` 已同步（HA 服务器 + 本地）
- [ ] R2 源图 HTTP 校验通过（status 200 + PNG）
- [ ] 线上 fetch no-store 复核版本一致
- [ ] 页面实测五项全过

## 陷阱

- 多码位 emoji（含 FE0F，如 🗺️）：用 Python 脚本写文件，编辑工具会损坏字节
- 数据文件：先拉后推、全量 diff（禁只比指定键）
- 缓存三处：HTTP 缓存 / SW CACHE / IndexedDB —— 版本递增 + 提示强刷
- 模组生物：不要浪费时间搜 ASB/DevKit（历史一次搜索数分钟无果），直接走白名单路径
- 终端可能吞输出/`python` PATH 随机失效 → 结果文件优先（脚本已写 `_last_*.txt`）
