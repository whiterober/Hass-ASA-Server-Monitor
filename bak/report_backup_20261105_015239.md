## 二、🔴 P0 — 线上已失效

### P0-1　`pwa/sw.js` 语法错误 → Service Worker 更新永久失败（旧版仍在跑）

**现象**

```
node --check pwa/sw.js
→ SyntaxError: missing ) after argument list   (sw.js:103)
```

**证据链**

| 项 | 值 |
|---|---|
| 本地 `pwa/sw.js` md5 | `bb3418d6ef9247392820921f5b108fb4` |
| 线上 `/sw.js` md5 | `bb3418d6ef9247392820921f5b108fb4`（**完全一致**） |
| 线上 `/sw.js` 大小 | 11,785 B，HTTP 200 |
| 前端注册处 | `dino-import.html` L3720 `navigator.serviceWorker.register('/sw.js').catch(function(){})` ← 错误被静默吞掉 |

**根因（已定位）**

中文注释在某次编辑中编码损坏（UTF-8 文本被按 GBK 处理后再存为 UTF-8，乱码特征命中 134 处），损坏时**吞掉了换行符**，导致三行代码被并进上一行的 `//` 注释中：

| 行 | 被注释吞掉的代码 | 后果 |
|---|---|---|
| L12 | `var RETRY_HTML = '<!doctype html>…'` | 断网兜底页未定义 |
| L65 | `if (req.mode === 'navigate') return;` | 导航请求拦截判断失效 |
| L69 | `if (url.pathname === '/' \|\| url.pathname === '/index.html') {` | **`{` 缺失 → 花括号失配 → 全文解析失败** |

**影响面（2026-11-05 浏览器实测更正）**

> 初版结论写的是「SW 完全没注册」，**实测推翻了这一条**：老客户端仍在正常用缓存。准确表述如下。

| 场景 | 实际表现 |
|---|---|
| **已装过旧版 SW 的设备**（如当前浏览器） | SW **正常工作中**，但版本**永久冻结在 2026-10-30**；11-02 之后所有 SW 侧改动一律不生效 |
| **新设备 / 清过站点数据 / 换浏览器** | `register()` 取到含语法错误的脚本 → 解析失败 → **完全没有 Service Worker**（无离线、无资源缓存、无兜底页） |
| 页面文档本身 | 新旧 SW 的 `fetch` 都不接管 `navigate` 请求，**页面始终走网络** → 所以「页面能打开」从来不是 SW 的功劳 |

**机制说明**：按 Service Worker 规范，新脚本解析失败时**不会卸载已激活的旧 worker**，只会在每次更新检查时静默失败 → 形成「看起来一切正常」的版本冻结。前端 L3720 的 `.catch(function(){})` 又吞掉了注册错误，因此无任何报错痕迹。

**时间线**

| 时间 | 事件 |
|---|---|
| 2026-10-29 19:04 | 最后一份语法完好的备份：`bak\dino_import_mapqual_20261029_191802\sw.js` |
| 2026-11-02 13:22 | 开始损坏：`bak\v5923_overlaytop_before\sw.js` 起全部 `node --check` 失败（共 130 份历史 sw.js，仅 10-29 及更早的 6 份通过） |
| 2026-11-04 00:06 | 当前 `pwa/sw.js`（仍损坏）随部署上线 |

> 注：`tmp/_sync_repack2.py` 用 `shutil.copy2` 原样复制 sw.js，**不是打包环节引入的损坏**，损坏发生在源文件编辑阶段。

**浏览器实测证据（2026-11-05，用户实际浏览器）**

| 检测项 | 实测值 |
|---|---|
| `navigator.serviceWorker.controller` | `https://dino.whiterober.ccwu.cc/sw.js`（**存在，说明 SW 正在控制页面**） |
| `getRegistrations()` | 1 个，`state = activated`，无 waiting / installing |
| `caches.keys()` | `dino-import-shell-v20261030-5743` / `-5744` / `-5745`（各 7 条，含 `/` 文档）、`dino-import-assets`（**1200 条**）、`dino-assets-v1`（**1192 条**，更早期遗留） |
| 本轮 244 个资源请求 | **239 个由 SW 处理**（`workerStart > 0`、`transferSize = 0`，如 `materialdesignicons.min.css`、`icon-192.png`、`values.json`） |
| 由缓存名可推 | 最后成功安装的 SW 是 **v20261030-5745**；当前文件自称 `v20261102-6028`，从未装上 |
| 线上 `sw.js` 响应头 | `Cache-Control: public, max-age=0, must-revalidate`、`CF-Cache-Status: HIT`、`ETag "12e4ed8f…"` |

**因此「每次都正确加载缓存」的真实来源**：SW（旧版，cache-first）+ Cloudflare 边缘缓存（HIT）+ 浏览器强制重校验（`max-age=0, must-revalidate`）三层叠加，**与当前这份坏掉的 sw.js 无关**。
