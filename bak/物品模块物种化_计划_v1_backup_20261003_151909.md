## 一、现状调查（线上 v4280 实测数据）

### 1.1 模块栏现状
- 模块栏内容 = `lbItemNoHaveByKind()['attachment']`，**当前 126 件**
- 数据来源：`汉化/item_zh.json` 词典 `kind` 字段（`attachment`）
- 关键规则：v3578 起 `OTHER` 集合（resource/ammo/consumable/attachment/trophy/dye/egg/structure/facility）**不过滤物种绑定**
  → attachment 组从未做物种绑定过滤（本题的漏洞来源）

### 1.2 可对应物种的判定（组合判据实测）
- 126 件中 **47 件可解析到物种**，79 件不可（应保留在模块栏）
- 47 件命中样例：
  - 机械类：`Spawner_Mek`→机甲、`Spawner_Enforcer`→执行者(Enforcer)、`Spawner_TekStrider`→泰克跨步者、`PrimalItem_Spawner_Exosuit`→Exo-Mek、`Spawner_HelperBot`→SIR-5rM8、`MekBackpack_Shield/MissilePod/SiegeCannon`→机甲、`ScoutUnassembled`→侦察机(Scout)
  - 载具类：`TrainEngine`/`TrainCar_Platform`→火车、`Raft`→木筏、`PrimalItemMotorboat`→摩托艇、`DinoSpawner_Zeppelin`→齐柏林飞艇、`PrimalItem_Spawner_HoverSkiff`→泰克悬浮艇
  - 滑翔翼：`Glider`→Maewing、`Glider_Thrall`→Thrall、`SeafinGlider`
  - 服装/皮肤：`Rex_Bone_Costume`→霸王龙、`BoneQuetzalCostume_Icon`→风神翼龙、`Rex_Ghost_Costume`、`HUD_GhostArgentavisCostume_Icon`→阿根廷巨鹰 等约 30 件
- 79 件不可解析（保持不动）：炮塔族（`Turret`/`TurretTek`/`HeavyTurret`/`AntiFlyerTurret`/`TurretBallista`/`TurretRocket`/`TurretMinigun`/`TurretCatapult`/`Cannon`）、`TeslaCoil`、武器附件（`Scope`/`HoloScope`/`Silencer`/`Flashlight`/`Laser`）、战车部件（`Car_*` 全族）、随伴装备（`DinoCompanion_Gear_*`）、`Submarine`/`Canoe`/`SaddleCart` 等

### 1.3 实例分布（决定显示口径）
- 有 q≥1 实例：`Spawner_Mek`(32)、`Spawner_Enforcer`(17)、`MekBackpack_Shield`(18)/`MissilePod`(12)/`SiegeCannon`(7)
- 仅未评级（q<0）：`Raft`(3)、`TrainEngine`(1)、`DinoSpawner_Zeppelin`(2) 等载具/滑翔翼
- **无任何实例**：服装/皮肤约 30 件、`Spawner_TekStrider`/`Exosuit`/`ScoutUnassembled` 等（→ 必须走「专门显示」的目录段）

### 1.4 装备榜现状（物种榜）
- TAB 定义：`LB_ITEM_RANK_KINDS`（line 7258）= 鞍(`saddle`) / 蓝图(`bp`)
- 桶索引：`lbRankEnsure()`（惰性全库扫描，键 `idx.sp[物种名][kind]`）
- 渲染唯一实现：`lbRankRenderPanel(p, ctx)`（物种/物品两端共用）
- 行卡：`lbRankRow(x, i, kindKey, arrIdx, sect)`；弹卡：`lbRankShowCard(kindKey, arrIdx)`（非鞍/非蓝图 → 实物大卡 `lbItemCardHtml`）
- 按钮显隐：`lbRankHasAny()`（遍历 kinds 看桶是否非空）；物品模式另走 `lbRankRenderItemPick`
- 物种键唯一源：`lbRankSpecies({class})`（① ASB `findSpeciesByClass().name` ② 物品名剥鞍后缀查 ASB 名表 ③ 词干表 `LB_RANK_STEM_FIX`(dino_rank_alias.json)/`LB_RANK_STEM_MAP`(ASB) ④ 字符串兜底）

## 二、设计（唯一源原则）

### 2.1 物品→物种解析函数（新增）
`lbItemSpAttachOf(base)`：仅对词典 `kind=attachment` 的物品生效，判据层级（全部数据驱动、零硬编码）：

1. **词干表**：`lbRankSaddleStem(base)` 产出的候选 → 查 `LB_RANK_STEM_FIX`（dino_rank_alias.json）→ `LB_RANK_STEM_MAP`（ASB 资产词干）→ 剥变体前缀（`lbRankStripVariant`）
2. **en 名包含物种英文名**：`lbItemMeta(base).en` 按**词边界**匹配 ASB 物种名（≥4 字符；最长者优先，防 `Rex` 误吃 `Rex Ghost`）
3. **zh 名包含物种中文名**：`lbItemMeta(base).zh` 包含物种中文名（≥2 字）
4. **类名词干**：base 剥 `PrimalItem*_` 前缀、去分隔符小写后，**词首/分隔边界**匹配 ASB 物种词干（≥3 字符，如 `mek`；防误配）
5. 命中后的物种必须**存在于物种浮窗权威表**（`lbSpKeysSorted().allCls` / ASB 名表映射），否则视为未命中（不猜）

- 缓存：`LB_ATTACH_SP_CACHE`，键 = `base + LB._cache.ts + ASB 物种数 + LB_RANK_STEM_FIX 就绪签名`
- 返回：物种权威名（与 `lbRankSpecies` 同口径，保证与物种按钮键一致）

### 2.2 模块栏移出（浮窗侧）
- 接入点：`lbItemNoHaveByKind()`（line 18940 附近）attachment 分组处理处
- 逻辑：`k==='attachment' && lbItemSpAttachOf(base)` → **占位**（`_seen[lbItemAggKey(base)]=1; _seen[lbCanonBase(base)]=1`，防同物孪生前缀键补位）→ `return`
- 影响：模块栏 126 → 预计 79 件；其它栏（建筑/资源/消耗/弹药/战利品/染料/蛋/器械其它段）不动
- 说明：本改动**只影响浮窗列表**；物品索引（`lbItemIsPick` 体系）、聚落卡角标、容器组渲染均不受影响

### 2.3 装备榜「模块」TAB（榜单侧）
1. `LB_ITEM_RANK_KINDS` 新增：`{ key:'attach', label:'模块', mineOnly:false, externalMax:5 }`
2. `lbRankEnsure()` 扫描时：
   - 预构建「模块物品 base 集合」= 126 项中 resolver 命中者（惰性缓存）
   - 扫描 `itemsByServer`：`lbBaseOfItem(it)` ∈ 集合 → 物种键 = `lbItemSpAttachOf(base)` → 入桶 `idx.sp[sp]['attach']`
   - **qidx 口径：全部实例**（含 q<0/0）——attach 专用（鞍/蓝图保持原 `qidx>0` 口径不变）
   - `mine` 判定沿用现有 `ps[sv:tribe]` 口径
3. **目录段（专门显示无实例物品）**：
   - `lbRankEnsure` 同时产出 `idx.sp[sp]._catalog`：resolver 命中该物种、但全库**无任何实例**的 base 列表
   - 渲染：`lbRankRenderPanel` 在「我的 / 外部更高」之后追加「目录（无实例）」段（新 ctx 字段 `catalog`），条目行卡显示图标+中文名+英文小字，点击弹实物大卡（伪 it：`class=base, kind='attachment', qidx=-1, rating=-1`）
   - **角标口径不变**：TAB 角标仍只计「我的」实例数；目录段不参与角标
4. 行卡/弹卡复用：
   - `lbRankRow`：`kindKey==='attach'` 时等价实物卡行为（评分徽章按 `rating>0` 显示）；catalog 条目加「目录」标记样式
   - `lbRankShowCard`：`attach` 落入现有 else 分支（实物大卡）即可；catalog 条目构造伪 it 后同路径
5. 按钮显隐：`lbRankHasAny()` 的 kinds 循环自动覆盖 attach（桶内**含目录段非空**也视为有内容 → 显示按钮）
6. 物品榜（`lbRankRenderItemPick`，v4209）**不变**

### 2.4 与既有口径的关系
- v4158「服装类不属物种绑定」仅作用于 armor/weapon/tek 栏的过滤场景；本次新需求明确「服装一并移出模块栏并专门显示」→ 在 attachment 栏 + 装备榜场景下生效，两者不冲突（不回改 v4158）
- v1368「物种体系已涉及的装备不重复收录」→ 本次是把 attachment 类补进该体系

## 五、风险与备选

| 风险 | 缓解 |
|------|------|
| en 名包含匹配误配（如 `Rex` 吃掉 `Rex Ghost...` 变体） | 词边界 + 最长匹配优先；解析结果表人工复核（S1） |
| 类名词干过短（`mek`）误配 | 词首/分隔边界判定；解析结果表复核 |
| 目录段与实例段排序冲突 | 目录段固定放行末，独立小标题 |
| 性能：`lbRankEnsure` 增加 resolver 调用 | resolver 结果按 base 缓存（126 项量级），首扫一次性 |
| 用户对目录段呈现形式有别的期望 | S3 前可再确认（如「服装」独立小节） |
