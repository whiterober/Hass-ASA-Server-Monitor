# 「追踪 / 追踪最近」全场景推广 — 详细计划（v1）

> 日期：2026-10-03 · 状态：**计划 v2（2026-10-03 范围修订：仅公共设施 + 聚落设备；待确认后分期实施）**（本文件为唯一实施依据）
> 目标：把「地图分布」里的 **追踪**（追这一只/这一个）与 **追踪最近** 推广到**所有存在地图点位的场景**；尽量复用（非复制）。

---

## 0. 用户口径（原话纪要）

1. 要将「地图分布」中的**追踪**以及**追踪最近**功能，推广到**所有存在地图点位的地方**；
2. **尽量复用（非复制）**方法；
3. 先在工作区生成**详细计划**（本文件）。

**2026-10-03 范围修订（v2，用户口径）**：
4. **限制范围：只推广到「公共设施」**（T2 公共设施面板）+ **离散聚落设备（非生物）**（T4b 聚落卡设施图）；
5. **「追踪最近」仅限于 T2 的 3 类**：**探险者笔记、深海/沙漠宝箱、河狸坝**（其余格子仅做点位打点）；
6. **不做**：T3 联盟成员分布、T4a 生物地图（`lbOpenBioMap`）、T2 其它类的"追踪最近"。

### 1.1 后端 API（`独立后端\dino_backend.py` 已上线）

## 3. 复用设计（非复制）— 新增 3 个通用件 + 抽取 2 处现有逻辑

> 原则：**一切追踪/打点/停止/持久化统一走现有 `LB._trackState` 状态机与 `lbTrackLoc/lbTrackStop` 链路**；新场景只做"入口壳"，不重写链路。

### R1 `lbTrackDotBtn(server, x, y, z, opts)` —— 通用「游戏内打点」按钮（新增，~30 行）
- 渲染统一样式按钮（🎯 打点 / 打点中… / 失败重试）；
- 点击处理（async）：
  1. `lbFindPlayerPos()`（或复用 `LB._trackState.pos`）→ **校验玩家在目标服**（范式同 `lbTrackWildFrom` L21620 的 toast 拒绝）；
  2. 互斥：`if(LB._trackState.tracking) await lbTrackStop(true)`（静默停止旧的）；
  3. `lbTrackLoc(server,x,y,z)` → 成功 `LB._trackState={tracking:true, server, pos, from:'dot'}` + `lbStartTrackPoll()` + `lbRenderBreedBar()`（悬浮控制组出现）；
  4. toast 结果（成功/失败原因）。
- `from:'dot'` 为新增来源标记：悬浮组=**仅停止**（同 card 语义）。

### R2 `lbDotTrackNearest(cfg)` —— 通用「追踪最近」（新增，~40 行）
- 入参：`{server, pts:[{x,y,z,name?}], container}`；
- 步骤：`lbFindPlayerPos()`（须在该服）→ **算最近点**（复用/参照 `lbNearestStructure(arr,cx,cy)` L5215，平面距离）→ `lbTrackLoc` 打点 → **就地 UI 定位高亮**（翻页居中用 `lbOpenDistSel` 的滚动段，高亮用 `lbWildPick` 的样式段）；
- 与 T1 的"追踪最近"（追野生实体链）**并列存在**：T1 追"会动的龙"（TrackDino），T2/T3/T4 打点"静态目标"（TrackLocation）——**同一悬浮控制组/同一停止命令**，用户感知一致。

### R3 `lbPlayerSrvPos()` —— 玩家位置缓存包装（抽取，~10 行）
- 包 `lbFindPlayerPos()` + `LB._playerPosCache`（30s TTL），供 R1/R2 共用，避免按住按钮反复全服查询。

### R4 抽取：`lbDotHl(el)` 点高亮（从 `lbWildPick` 内提取样式段，两处复用）
### R5 抽取：`lbPageScrollTo(container, abbr)` 翻到目标服页（从 `lbOpenDistSel` 提取滚动段）

## 4. 逐场景改造清单（可执行级）

### T2 公共设施面板（**唯一"追踪最近"场景**）
- **P2-a（点位打点，全类别）**：`lbFacPosPage` 点位徽章（现 `d.lat+' '+d.lon`）内追加 `lbTrackDotBtn(abbr, x, y, z)`；多点页=每个点位各自按钮（数据点在 `arr`/`dots` 内，含 server=该页 abbr）。
- **P2-b（页头"追踪最近"，仅 3 类）**：[🎯追踪最近] 按钮**仅当格子为 `t:explorerchest`（探险者笔记）/`t:seacrate`（深海·沙漠宝箱）/`t:beaverdam`（河狸坝）时显示**；点击 → `lbDotTrackNearest({server, pts})`（仅当**当前页服=玩家所在服**，否则置灰+提示）。
- 判定语义：**该类别全部点位都是静态目标 → 一律 TrackLocation 打点**（无 TrackDino 分支）。

### T3 联盟成员分布 —— **v2 移除，不做**
（原设想：成员点打点/最近成员；用户口径限定"只推广到公共设施"，本场景整体移出。）

### T4 聚落卡内嵌地图 —— **v2 拆分：仅做设施图（非生物）**
- **T4b（做）**：`lbOpenFacMap` 地图块下方追加 [🎯 游戏内打点]：单设施=该点；多设施=默认打"离玩家最近的一点"（`lbTrackDotBtn`/`lbDotTrackNearest`，**不含"追踪最近"按钮**）。
- **T4a（不做）**：`lbOpenBioMap`（生物地图）——用户口径"非生物"。

### 共享
- 所有入口共用：**玩家在服校验**、**互斥 stop**、**LB._trackBusy 防并发**、**悬浮控制组（切换隐藏：from!=='nearest' 只显示停止）**、**持久化**。

| # | 边界 | 现状/对策 | 验证方式 |

## 7. 验证计划（每期）

1. **PW 功能链**：点按钮 → 状态文件 `track_dino_status` ts 变化 + `ok:true` → toast 文案正确；
2. **游戏内**（用户侧）：HUD 出现目标标记/箭头；`StopTrackDino` 后清除；
3. **回归**：T1 物种分布（点选/追踪/切换/停止/route）零回归；设施浮窗既有徽章交互（`lbFacDotTap`）不破坏；聚落卡（T4b）打开/关闭不影响既有卡片交互；
4. **边界**：B1 跨服拒绝、B3 离线提示、（B2 手测结论回填本文件）。

## 8. 风险与依赖

- **依赖**：后端三 API 已上线（无新增依赖）；`track_dino_status` 轮询机制已稳定；
- **风险**：RCON 打点频次（每点一次=1 条 RCON）——UI 做防抖（打点中禁用）；多点场景不批量；
- **不做**：不新增"跟踪打点跟随移动"（超范围）；不改 T1 既有逻辑（仅抽公共段，需保持行为一致）；**不做 T3 成员分布 / T4a 生物地图 / T2 其它类"追踪最近"**（v2 范围口径）。
