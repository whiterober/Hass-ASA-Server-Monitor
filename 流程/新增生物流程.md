# 新增生物流程

> 状态：✅ 已实施（新架构完整链路）
> 目标：游戏服务器新生物（新 DLC/新物种）上线后，让 dino-import 页面正确识别、显示、搜索该生物
> 涉及：数据导出（游戏服）→ 静态数据（HA/CF Pages）→ 前端显示（dino-import.html）

---

## 新生物显示链路

```
游戏服插件导出 exe（D:\ASA\Saved\DinoData\*_cryo.json / *_tamed.json）
   │  dinoClass（蓝图类名如 Argent_Character_BP_C）
   ▼
前端 dino-import.html
   ├─ findSpeciesByClass(dinoClass) → values.json/ASA-values.json 物种库
   ├─ zhName(dinoClass) → LB_SPECIAL_NAMES 手动翻译 → icon_zh_map.json → lbZhDeep
   ├─ 图标：lbIconForDinoClass → LB_ICON_BY_NAME（icons2.json biology/units + WebP 缩略图）
   └─ 归属：lbIsTameableCls（可驯服判断）+ LB_EXTRA_FORCE/LB_TAMEABLE_FORCE 特殊表
```

## 判断新生物是否已支持（先查）

打开页面后搜索新生物名称，若**搜不到 / 无图标 / 显示英文未翻译**，按下方流程补全。

| 环节 | 缺失表现 | 处理位置 |
|------|---------|---------|
| 物种库 | 搜不到（无数据） | `values.json` / `ASA-values.json`（ASB 物种库） |
| 中文名 | 显示英文 | `LB_SPECIAL_NAMES` 或 `icon_zh_map.json` |
| 图标 | 无图/破图 | `icons2.json` + R2 源图 + 增量压图 |
| 可驯服归属 | 归错区（如特殊生物） | `LB_TAMEABLE_FORCE` / `LB_EXTRA_FORCE` |
| 数据 | 有图但无生物记录 | 游戏服导出 exe（检查是否导出该 dinoClass） |

## 完整流程（按需执行）

### 第 1 步：确认数据导出（游戏服）

- 生物数据由游戏服插件导出 exe 生成 `*_cryo.json` / `*_tamed.json`（`D:\ASA\Saved\DinoData\`）
- 确认新生物的 `dinoClass` 已出现在导出 JSON（如无 → 需改导出 exe 支持新蓝图类名）
- 数据经 DinoDataGzipWatcher gzip → Qsync 同步 NAS → 前端拉取

### 第 2 步：物种库（ASB 数据）

`values.json` / `ASA-values.json` 是 ASB（ARK Smart Breeding）物种数据库：
- `values.json` = 官方物种全量（老）
- `ASA-values.json` = ASA 追加物种（新版）
- 前端 `loadASB()` 合并两者（L369-379）
- 若新生物不在物种库 → 需更新 ASB 数据（从最新 ARK Smart Breeding 导出/更新），打包时自动拉取（`_sync_repack2.py` L20-21 从 `/homeassistant/www/` 拉）
- **GitHub 更新源（dev 分支最新）**：`cadon/ARKStatsExtractor` **dev** 分支 `ARKBreedingStats/json/values/ASA-values.json`（2026-08-28 实测 dev=92.43.1 > 服务器 91.1.1 > master 87.11.4）；拉取升级时用 dev 分支，勿用 master

### 第 3 步：图标（R2 + 增量压图）

1. **上传源图到 R2**：将新生物 PNG 上传到 R2 `ASA/biology/<Species>.png`（img.whiterober.ccwu.cc）
2. **更新 icons2.json**：HA 的 `/config/www/asa-data/icons2.json` 增加条目 `{name, url}`（url = `https://img.whiterober.ccwu.cc/ASA/biology/<Species>.png`）
3. **增量压图**：跑 `python _webp_incremental.py`（生成 96px WebP 缩略图 + 更新映射）→ 重新打包部署（见「增量压图流程」）

### 第 4 步：中文名（翻译）

优先级从高到低：
1. `LB_SPECIAL_NAMES`（dino-import.html L428，手动精确翻译，最高优先）
   ```javascript
   '新类名_Character_BP_C': '中文名',
   ```
2. `icon_zh_map.json`（汉化/ 生成，搜索词条）
3. 自动翻译 `lbZhDeep`（从汉化 JSON 深度查找）
4. 后缀/前缀规则（`_Lunar`→月球、`_VDay`→情人节、`_Rare`→稀有）

> ⚠️ 若新生物需特殊处理（重名表变体/括号后缀），用 `LB_SPECIAL_NAMES` 最稳妥。

### 第 5 步：可驯服归属（特殊表）

- **默认**：有 `fullStatsRaw` 的物种 → 归「未驯服」野生区
- **强制归特殊生物折叠区**：加入 `LB_EXTRA_FORCE` 数组（如不可拥有生物）
- **强制归可驯服区**：加入 `LB_TAMEABLE_FORCE` 数组（如侦察机 RemoteCamera）

> ⚠️ 完整归类（含「预览」组与双源同步）见下方「v2 增补 · 浮窗归类规则」；**删除/移出清单项必须同时改 `dino_rules.json`**（否则页面加载时旧名单回灌）。

### 第 6 步：前端打包部署

1. 修改 `dino-import.html`（LB_SPECIAL_NAMES / LB_EXTRA_FORCE / LB_TAMEABLE_FORCE 等）
2. **递增 `LB_VERSION`**（如 `v20260828-351` → `v20260829-352`）——触发旧版玩家版本自检刷新 + 静态 JSON 缓存失效
3. 跑 `python tmp\_sync_repack2.py` 打包（自动生成 version 文件）
4. 浏览器上传 CF Pages 部署
5. 验证：页面搜新生物 → 图标/中文名/归属正确

## 常见问题

### Q1：新生物搜不到
- 检查 `values.json`/`ASA-values.json` 是否含该物种 → 更新 ASB 数据
- 检查前端是否跑旧版（版本自检提示 → 刷新）

### Q2：有记录但显示英文
- 加 `LB_SPECIAL_NAMES` 手动翻译最稳妥
- 或更新 `icon_zh_map.json`

### Q3：无图标
- R2 源图是否上传？`icons2.json` 是否含条目？缩略图是否生成？

### Q4：归错区（野生/特殊）
- 用 `LB_TAMEABLE_FORCE`（归可驯服）或 `LB_EXTRA_FORCE`（归特殊）

### 浮窗归类规则（2026-10-16 用户口径）

新生物**必须加进物种浮窗**（选物种浮窗）；归类判据看 **ASB 物种库**：

| ASB 状态 | 归类 | 前端动作 |
|----------|------|---------|
| **无数据**（物种库未收录） | 统一收浮窗特殊区**「预览」**分隔组（原「测试」，待 ASB 收录后移出正式归类） | `LB_TEST_EXTRA` 加类名 + `LB_SPECIAL_NAMES` 加显示名（汉化） |
| **有数据** | 按情况归类 | 默认可驯→正式区（未驯服/变体）自动入位；偷蛋龙→`LB_STEAL_EGG`（可偷蛋组）；载具/机械→`LB_OWNED_UNITS`（可拥有组）；渔获→`LB_CATCHABLE_FISH`（可捕获组）；其余特殊→`LB_EXTRA_FORCE`；被误隐藏→`LB_TAMEABLE_FORCE` |

> 依据：v454「预览」组标准（ASB 未收录即收入）；v450 猪/昆卡案例（无 ASB 数据统一收「预览」区）；特殊归类判定提前于自动分类（v814）。

> ⚠️ **双源铁律（2026-10-16 v4668 血泪）**：归类清单存在**两个数据源** —— `dino-import.html` 硬编码数组 + `dino_rules.json`；页面加载 `lbRulesLoad()`→`lbRulesMerge()` **并集合并**：
> - `_union` = **并集追加（只加不减）** ⇒ **删除/移出清单项必须同时改 `dino_rules.json`**，否则旧名单**回灌**、页面无变化；**新增**任一即可（双端同步最稳）；**改名**双端同步（`_obj` 补键不覆盖，html 优先）
> - `dino_rules.json` = **手工混合格式**（indent 1、短数组单行）⇒ **禁止 `json.dump` 重写**；字符串级替换（锚 count==1 断言 + `json.loads` 校验 + 备份）
> - 机械检查：任务「新生物:⑥ 双源一致性检查」（`流程\工具\rules_sync_check.py`）；改后 bump `LB_VERSION` + `pwa/sw.js` VER → 部署 → 运行时验证
> - 案例：v4667 移出 11 项只改 html 无效（JSON `testExtra` 旧 15 条回灌）→ v4668 双源同改后生效（`.copilot\进度\055` 补充 3/4）

### 工具脚本（`流程\工具\`）

- `class_lookup.py <生物名>`：权威链 = PO（含 Mods 路径，英文命中强）→ **ASB 物种库（blueprintPath 直出类名，先跑 ⓪）** → CSV（中文 Key 回查）→ dino-import 手动表（LB_SPECIAL_NAMES 键值对）→ icon_zh_map → wiki → ArkKit 兜底。结果文件 `_last_class_lookup.txt`
