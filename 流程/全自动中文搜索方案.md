### 当前搜索逻辑

```javascript
// asa-admin.html L6581 filterIconPicker
var name = el.getAttribute("data-name").toLowerCase();   // 文件名
var cnName = (iconZhMap[name] || "").toLowerCase();      // 中文映射
var matchSearch = !q || name.includes(q) || cnName.includes(q);
```

**痛点**：`data-name` 等于原始文件名（如 `HUD_FishingTrophyMount_SabertoothSalmon_Icon`），用户搜 `fish`、`salmon`、`三文鱼` 均无法命中。

## 后端：增强 `icon_zh_map.json`（`_build_icon_zh_map.py`）

### 追加逻辑

脚本现有逻辑生成 `result`（{en_name: zh_name} 映射表）。末尾追加：

```python
# === 追加：token 词典推断，补齐中文覆盖到 93% ===

# 1. 构建 token→中文词典
token_cn = {}
for en_name, zh_name in result.items():
    zh_clean = re.sub(r'\[.*?\]', '', zh_name).strip()
    for tok in re.split(r'[ _]+', en_name.lower()):
        if len(tok) >= 3 and not tok.isdigit():
            token_cn.setdefault(tok, set()).add(zh_clean)

print(f"  Token dict: {len(token_cn)} entries")

# 2. 为所有图标推断中文（只补缺失的）
added = 0
for item in icons:
    name = item.get('name', '').lower()
    if name in result:
        continue  # 已有翻译，跳过
    # 去前后缀 + 拆 token
    clean = re.sub(r'^HUD_', '', name)
    clean = re.sub(r'_Icon$', '', clean)
    clean = re.sub(r'([a-z])([A-Z])', r'\1 \2', clean)
    tokens = [t for t in re.split(r'[ _]+', clean.lower()) if len(t) >= 3 and not t.isdigit()]
    zh_kw = set()
    for t in tokens:
        if t in token_cn:
            zh_kw.update(token_cn[t])
    if zh_kw:
        result[name] = ' '.join(list(zh_kw)[:3])  # 最多 3 个关键词
        added += 1

print(f"  Inferred: {added}")
print(f"  Total zh_map: {len(result)}")
```

> 输出：单一增强版 `icon_zh_map.json`，覆盖 93%。与现有流程 100% 兼容。

## 前端：动态英文 token 匹配（`asa-admin.html`）

改 `filterIconPicker`（L6581），仅加 1 行：

```javascript
// 改前
var matchSearch = !q || name.includes(q) || cnName.includes(q);

// 改后
var nameTokens = q ? name.replace(/_/g, ' ').toLowerCase().split(' ').filter(function(t){return t.length>=2;}) : [];
var matchSearch = !q || name.includes(q) || cnName.includes(q)
    || nameTokens.some(function(t){return t.includes(q);});
```

效果：

| 搜 | `HUD_FishingTrophyMount_SabertoothSalmon_Icon` 的 token | 命中 |
|----|------|:---:|
| `fish` | fishing | ✅ |
| `salmon` | salmon | ✅ |
| `trophy` | trophy | ✅ |
| `mount` | mount | ✅ |
| `三文鱼` | icon_zh_map 推断 → `狩猎战利品 鞍具 三文鱼` | ✅ |
